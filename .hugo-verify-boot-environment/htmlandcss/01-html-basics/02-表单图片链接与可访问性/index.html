表单、图片、链接与可访问性：让页面真的可用

August 19, 2026

HTML 不只是把内容显示出来，还要让用户能够输入、点击、提交、阅读，并让辅助工具也能理解页面。小白学习时常常只关注“浏览器里看起来有没有”，但真实页面更关心“用户能不能正确使用”。

这一篇讲表单、图片、链接和基础可访问性。

一、表单的基本结构

表单使用 form：

<form>
  <label for="username">用户名</label>
  <input id="username" name="username" type="text">

  <label for="password">密码</label>
  <input id="password" name="password" type="password">

  <button type="submit">登录</button>
</form>

重点：

  • label 说明输入框含义。
  • for 对应输入框的 id。
  • name 表示字段名。
  • type 表示输入类型。

点击 label 时，浏览器会自动聚焦对应输入框。这是很小的体验细节，但小细节积累起来就是专业。

二、常见 input 类型

<input type="text">
<input type="password">
<input type="email">
<input type="number">
<input type="checkbox">
<input type="radio">
<input type="file">

不同类型会影响：

  • 浏览器默认校验。
  • 移动端键盘类型。
  • 输入交互。
  • 表单提交值。

例如邮箱：

<input type="email" name="email">

移动端可能会显示更适合输入邮箱的键盘。

三、textarea 和 select

多行文本：

<label for="intro">个人简介</label>
<textarea id="intro" name="intro"></textarea>

下拉选择：

<label for="level">学习阶段</label>
<select id="level" name="level">
  <option value="beginner">入门</option>
  <option value="advanced">进阶</option>
</select>

表单控件要配合标签和字段名，不能只写一个孤零零的输入框。

四、表单校验属性

HTML 内置一些基础校验：

<input type="text" required minlength="2" maxlength="20">
<input type="number" min="1" max="100">

这些校验适合做基础限制，但不能替代 JavaScript 校验，更不能替代后端校验。

前端校验负责体验，后端校验负责安全和数据正确性。

五、按钮类型

表单里的按钮有类型：

<button type="submit">提交</button>
<button type="reset">重置</button>
<button type="button">普通按钮</button>

如果不写 type，按钮在表单中默认可能是提交按钮。小白常见问题之一就是点击普通按钮却触发表单提交。解决办法很简单：明确写类型。

六、链接的语义

链接用于跳转：

<a href="/posts/1">查看文章</a>

按钮用于触发动作：

<button type="button">打开弹窗</button>

不要混用：

  • 跳转页面，用 a。
  • 执行动作，用 button。

当然，框架和组件库会封装这些行为，但底层语义依然存在。

七、图片显示

基础写法：

<img src="/images/post-cover.jpg" alt="文章封面">

常见 CSS：

.cover {
  width: 100%;
  height: 180px;
  object-fit: cover;
}

object-fit 常用值：

值 效果
cover 填满容器，可能裁剪
contain 完整显示，可能留空
fill 强行拉伸，可能变形

头像通常用 cover，商品图或证件图可能更适合 contain。

八、可访问性基础

可访问性不是额外负担，它让更多用户能正常使用页面，也让代码结构更规范。

基本规则：

  • 图片写 alt。
  • 输入框配 label。
  • 按钮写清楚可理解的文本。
  • 不要只靠颜色表达状态。
  • 可点击元素要有正确语义。
  • 标题层级不要乱跳。

不推荐：

<div onclick="submit()">提交</div>

推荐：

<button type="button">提交</button>

浏览器已经给按钮提供了键盘聚焦和默认交互。既然有现成正确答案，就没必要自己创造错误答案。

九、ARIA 简单了解

ARIA 可以补充语义，但不要滥用。

<button type="button" aria-label="关闭弹窗">×</button>

当按钮只有图标时，aria-label 可以告诉辅助工具它的含义。

不过优先使用正确 HTML 标签。ARIA 是补充，不是用来掩盖结构混乱的万能贴纸。

十、练习

写一个登录表单：

  • 用户名输入框。
  • 密码输入框。
  • 记住我复选框。
  • 登录按钮。
  • 忘记密码链接。

要求：

  • 每个输入框都有 label。
  • 登录按钮使用 type="submit"。
  • 忘记密码使用 a。
  • 记住我使用 checkbox。

表单是前端最常见也最容易暴露基础问题的地方。能把普通表单写规范，已经迈过了一个很实际的门槛。
