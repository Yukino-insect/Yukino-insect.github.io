响应式布局与移动端适配：让页面在不同屏幕上都能用

August 19, 2026

页面不会只在你的电脑上显示。它可能出现在手机、平板、笔记本、外接显示器、小程序容器、WebView 中。响应式布局就是让页面在不同尺寸下仍然可读、可操作、结构稳定。

一、视口

移动端页面必须写：

<meta name="viewport" content="width=device-width, initial-scale=1.0">

它告诉浏览器页面宽度等于设备宽度。如果没有它，移动端浏览器可能按桌面宽度缩放页面。

二、不要写死宽度

不推荐：

.page {
  width: 1200px;
}

推荐：

.page {
  width: min(100%, 1200px);
  margin: 0 auto;
  padding: 16px;
}

这样大屏有最大宽度，小屏不会横向溢出。

三、媒体查询

媒体查询根据屏幕条件应用样式。

.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
}

@media (max-width: 768px) {
  .grid {
    grid-template-columns: 1fr;
  }
}

这表示屏幕宽度不超过 768px 时，卡片改成单列。

四、移动优先

移动优先是先写小屏样式，再为大屏增强。

.grid {
  display: grid;
  grid-template-columns: 1fr;
  gap: 12px;
}

@media (min-width: 768px) {
  .grid {
    grid-template-columns: repeat(2, 1fr);
  }
}

@media (min-width: 1024px) {
  .grid {
    grid-template-columns: repeat(3, 1fr);
  }
}

这种方式适合内容型页面和移动端优先产品。

五、自适应 Grid

不想写多个断点时，可以用：

.grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(240px, 1fr));
  gap: 16px;
}

它会根据容器宽度自动决定列数。

六、图片响应式

基础写法：

img {
  max-width: 100%;
  height: auto;
}

固定比例封面：

.cover {
  width: 100%;
  aspect-ratio: 16 / 9;
  object-fit: cover;
}

aspect-ratio 可以让图片容器保持稳定比例，减少加载前后布局跳动。

七、文字和按钮

移动端要注意：

  • 按钮点击区域不能太小。
  • 文字不能靠屏幕边缘太近。
  • 长单词、长链接、长标题要能换行或省略。
  • 表单输入框要足够高。

示例：

.button {
  min-height: 40px;
  padding: 0 16px;
}

.title {
  overflow-wrap: anywhere;
}

八、安全区域

部分手机有刘海屏和底部手势区域，可以使用安全区域变量：

.bottom-bar {
  padding-bottom: env(safe-area-inset-bottom);
}

在跨端和移动 Web 中，底部固定按钮尤其要注意安全区域。

九、滚动容器

页面滚动和局部滚动要分清。

.panel {
  max-height: 400px;
  overflow: auto;
}

如果 overflow 设置在错误的父元素上，可能导致 sticky 失效、滚动穿透、内容被裁剪。

十、响应式检查清单

  • 小屏是否出现横向滚动。
  • 图片是否变形。
  • 卡片是否能自动换行。
  • 按钮是否容易点击。
  • 文字是否溢出容器。
  • 固定底栏是否避开安全区域。
  • 弹窗在小屏是否超出视口。

十一、练习

实现一个文章列表：

  • 手机端单列。
  • 平板端两列。
  • 桌面端三列。
  • 图片比例固定为 16:9。
  • 标题最多两行。
  • 卡片宽度不写死。

响应式不是让页面在所有设备上完全一样，而是让它在每个设备上都合理。
