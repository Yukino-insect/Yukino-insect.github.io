MySQL 专题索引

August 21, 2026

这个目录用于整理 MySQL 和关系型数据库开发中最常遇到的问题。阅读时可以按下面的顺序走：先补基础 SQL 和索引，再看事务、锁、复制，最后看工程实践。

一、基础和查询

  1. 数据库 ：关系型数据库、SQL 基础、存储引擎和索引入门。
  2. SQL 的执行顺序 ：SELECT 的逻辑执行顺序，以及 MySQL 服务层、存储引擎层的执行链路。
  3. SQL JOIN 与 ON、WHERE 的区别 ：内连接、左连接，以及 ON 和 WHERE 在外连接中的语义差异。
  4. MySQL 中 IN 条件的查询机制 ：常量 IN、子查询 IN、IN 与 OR 的执行差异。
  5. sql 递归 ：用 WITH RECURSIVE 查询树形结构。

二、索引和性能

  1. 索引 ：索引类型、B+ 树、聚簇索引、唯一性校验、索引失效和深分页。
  2. MySQL 排序 ：ORDER BY 的索引排序、filesort、临时表和优化方式。
  3. 自增主键的使用 ：自增主键的优缺点、回滚不回退、分布式 ID 和逻辑删除下的主键设计。

三、事务、锁和一致性

  1. MySQL 事务 ：ACID、隔离级别、MVCC、锁类型和事务控制。
  2. FOR UPDATE ：什么时候需要当前读和行锁，什么时候只靠唯一索引或普通查询即可。
  3. 数据库事务的边界 ：数据库连接、schema、多数据源和 Spring @Transactional 的边界。
  4. 多数据源 ：多数据源的使用场景、事务风险和工程落地建议。

四、架构和对象

  1. MySQL 主从复制 ：复制链路、binlog、延迟、故障切换和读写分离。
  2. mysql 视图 ：视图的本质、适用场景、可更新限制和性能边界。
  3. Schema 模式 ：PostgreSQL schema 和 MySQL database 命名空间的差异。
  4. 数据库操作系列二三事 ：主键、类型映射、逻辑删除、动态条件和迁移变更的实践清单。
