Vue 3 与 uni-app 工程实战课程

August 21, 2026

这套 Vue 专题面向已经掌握 HTML、CSS、JavaScript 基础，想把 Vue 真正用于业务项目的学习者。它不会只停留在 v-if、v-for、ref 这些 API 名词上，因为那样学完之后通常只会得到一种错觉：好像会 Vue 了，但一遇到登录、接口、分页、权限、错误态、构建部署，代码立刻开始东倒西歪。很遗憾，项目不会因为你背过 API 就变得体贴。

课程按真实前端应用的成长路径组织：先理解 Vue 页面和响应式，再拆组件、管状态、处理接口和表单，最后进入路由、跨端、测试、性能、部署和大型项目结构。每篇文章最后都给出可运行练习，综合练习则从零搭建一个“文章管理后台”小项目，把组件、Pinia、路由、表单、错误态和本地模拟接口串起来。

课程地图

1. Vue 3 核心基础

这一章解决“Vue 页面到底怎样工作”。重点不是记住模板语法，而是理解状态如何驱动视图，模板、脚本、样式各自承担什么职责。

  • Vue 学习路线：从页面语法到前端工程能力
  • 单文件组件与模板语法：Vue 页面是怎样组成的
  • 响应式原理与组合式 API：ref、reactive、computed 和 watch

2. 组件、状态与数据流

这一章进入真实业务页面：组件如何拆，父子组件怎样通信，接口请求如何封装，Pinia 该管什么，表单和列表又该如何处理异常状态。

  • 组件通信、插槽与组合函数：把复杂页面拆得有秩序
  • 接口请求、Pinia 与前端数据流：把服务端数据管起来
  • 表单、列表、错误态与权限：真实业务页面绕不开的细节

3. Vue 工程实践与跨端

这一章把 Vue 从“能写页面”推进到“能上线维护”。路由、uni-app、性能优化、测试、构建部署和大型目录结构，是项目长期可维护的基本骨架。

  • 路由、页面结构与 uni-app 工程：从单页到跨端应用
  • 性能优化、测试、构建与部署：让 Vue 项目经得起上线
  • 大型前端项目代码组织：目录分层、模块边界和可维护性
  • 前端如何调试、查看日志与寻找错误：从现象到根因的实战流程
  • 浏览器开发者工具如何打断点：从暂停代码到定位问题

4. 最终综合练习

这一章不再讲单点知识，而是把它们组装成一个可运行的小项目。项目规模不大，但刻意覆盖了实际工作里最常见的麻烦：登录态、文章列表、搜索、分页、创建文章、详情页、点赞、权限、错误提示和路由守卫。

  • 综合练习：Vue 3 文章管理后台

推荐学习顺序

  1. 先读 01-vue-core/，把 Vue 页面、模板和响应式讲清楚。
  2. 再读 02-state-data/，把组件拆分、接口请求、Pinia 和业务状态串起来。
  3. 接着读 03-engineering/，补齐路由、uni-app、性能、测试、构建和目录边界。
  4. 最后完成 04-final-project/，用一个小项目把前面的知识真正跑通。

学习方法

每一篇文章都建议带着三个问题读：

  1. 这段状态应该放在组件内、父组件、Pinia，还是 URL 里？
  2. 这个页面除了成功状态，还需要处理哪些失败、空态和权限状态？
  3. 这段代码如果三个月后需求变化，我能不能清楚地知道该改哪里？

能持续回答这三个问题，才算从“会写 Vue 语法”走向“能写 Vue 项目”。只是让页面亮起来并不难，让它在需求变化、接口波动和多人协作中还保持清醒，才是前端工程能力。
