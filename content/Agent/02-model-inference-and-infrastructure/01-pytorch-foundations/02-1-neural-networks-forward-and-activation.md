上一节的 `nn.Linear` 已经悄悄展示了神经网络最小的组成部分，但“创建一个线性层，再把它连起来”并不足以解释网络为何有用。本篇先把神经元、层、参数和前向传播拆开；然后说明为什么中间必须出现激活函数。理解这些内容后，`nn.Sequential` 不再是一串恰好能运行的 API。

## 神经网络究竟是什么

在本课程中，**神经网络**可以准确而朴素地理解为：由多层可学习的数值变换组成的函数。它接收输入 $x$，经过若干次计算，输出预测 $\hat y$。所谓“学习”，是根据训练数据调整这些计算中的参数，使预测和正确答案更接近。

不要把“神经元”理解为生物大脑的精确复制。它只是一个计算单元：先对输入加权求和，再加上偏置，得到一个数。

$$
z=w_1x_1+w_2x_2+\cdots+w_dx_d+b
$$

其中 $x_1 \ldots x_d$ 是输入特征，$w_1 \ldots w_d$ 是权重，$b$ 是偏置。权重表示各特征在当前模型中的作用，偏置让模型不必被迫经过原点。它们都是训练会修改的**参数**；输入 $x$ 则是每条样本给定的数据，不能被优化器擅自改写。

例如，两个输入特征经过三个神经元，可以产生三个中间分数：

```text
输入 x = [x1, x2]
       │
       ├─ 权重、偏置 A ─→ z1
       ├─ 权重、偏置 B ─→ z2
       └─ 权重、偏置 C ─→ z3
```

把同一层所有神经元一起计算，就得到**全连接层**（fully connected layer，也叫线性层）。PyTorch 中的 `nn.Linear(2, 3)` 正是“每条输入有 2 个数，输出 3 个数”的层；它不是自动判断任务类型的万能模型。

## 从单条公式到一个 batch

单条样本的公式可以写得很长，实际训练会同时处理 $B$ 条样本。把它们排成矩阵后，线性层的计算可简写为：

$$
Z=XW^T+b
$$

- $X$ 的形状为 `[B, d]`：`B` 条样本、每条 `d` 个特征；
- `nn.Linear(d, h)` 的权重 $W$ 形状为 `[h, d]`：`h` 个输出各有 `d` 个权重；
- $Z$ 的形状为 `[B, h]`：每条样本得到 `h` 个中间分数；
- $b$ 的形状为 `[h]`，会通过广播加到每一行。

下面的代码不训练，只验证形状与公式。`torch.no_grad()` 表示这只是观察数值，不必记录之后求导所需的历史。

```python
import torch
from torch import nn

torch.manual_seed(7)

x = torch.tensor([[1.0, 2.0], [3.0, 4.0]])  # [B=2, d=2]
layer = nn.Linear(in_features=2, out_features=3)

with torch.no_grad():
    z = layer(x)

print('输入形状：', x.shape)       # [2, 2]
print('权重形状：', layer.weight.shape)  # [3, 2]
print('偏置形状：', layer.bias.shape)    # [3]
print('输出形状：', z.shape)       # [2, 3]
```

`layer.weight` 和 `layer.bias` 是 `nn.Parameter` 对象：它们属于模型、默认会被自动求导追踪，也会被 `model.parameters()` 交给优化器。不要把 `layer.weight.data` 当成日常修改参数的入口；绕过 autograd 随意原地改动，会使训练状态难以推理。需要查看数值时使用 `detach()`，需要训练时让优化器负责更新。

## 只有线性层，叠再多层仍然不够

一个容易忽略的事实是：线性变换接着线性变换，整体还是线性变换。若有两层：

$$
h=XW_1+b_1,\qquad z=hW_2+b_2
$$

把第一式代入第二式，仍可以化为 $XW+b$ 的形式。因此，单纯堆叠 `Linear → Linear → Linear` 虽然写出了很多层，却没有得到能够表达复杂弯曲边界的新能力。名字很长，能力却没有相应增加，这种不对称并不罕见。

以 XOR 为例：两个输入中恰有一个为 `1` 时标签为 `1`。四个点无法用一条直线分开；一个线性分类器不能同时正确处理它们。神经网络需要在层与层之间加入非线性变换，才能把输入空间折叠、弯曲成更适合分开的形状。

## 线性层、隐藏层和输出层不是固定的“三层机器”

这三个词经常被教材写在同一张图上，因此初学者容易以为每个神经网络都必须恰好有一个线性层、若干隐藏层和一个输出层。更准确的理解是：它们描述的是**功能位置**，不是框架强制规定的物理层级。

- 输入层表示数据进入模型的接口，通常不对应一个需要训练的 `nn.Module`；
- 隐藏层是中间表示，可能由 `Linear + ReLU`、`Conv2d + SiLU`、注意力和归一化组成；
- 输出层把最后的表示映射到任务需要的空间，例如回归的一个数、二分类的一个 logit、多分类的 `C` 个 logit。

一个最小二分类器可以只有 `Linear(2, 1)`；图像网络可能没有任何 `nn.Linear`，而 Transformer 的“隐藏层”主要由注意力和前馈网络构成。所谓“大模型”也不是把三种固定层各放大一次，而是把许多可学习函数组合起来：

$$
f(x)=f_n(\cdots f_2(f_1(x)))
$$

`nn.Sequential` 只是顺序组合这些函数的容器，`forward()` 则定义实际的数据流。激活函数是其中一个函数 $g$，例如 `ReLU(z)=max(0,z)`；整个网络函数 $f$ 还包含线性变换、卷积、注意力、残差相加等操作。把“激活函数”和“模型函数”当成同一个概念，就无法解释为什么一个网络可以在不同位置使用不同激活，或者输出层有时根本不接激活。

可以用下面的代码观察“结构是工程选择，而不是固定仪式”：

```python
from torch import nn

mlp = nn.Sequential(nn.Linear(2, 8), nn.ReLU(), nn.Linear(8, 1))
linear_only = nn.Linear(2, 1)

print(mlp)          # 一个隐藏表示 + 输出映射
print(linear_only)  # 没有显式隐藏层的最小模型
```

二者都实现了“输入到输出”的函数，但表达能力、参数量和适用任务不同。模型结构应由数据结构、任务输出和资源约束决定，而不是从“必须存在的层名”反推。

## 激活函数：在何处引入非线性

激活函数 $a=g(z)$ 对每个元素独立计算，通常放在隐藏层线性输出之后：

```text
输入 [B, 2]
  → Linear(2, 8) → 原始中间分数 [B, 8]
  → ReLU        → 非线性隐藏表示 [B, 8]
  → Linear(8, 1) → 输出分数 [B, 1]
```

最常见的 `ReLU`（Rectified Linear Unit）定义为：

$$
\operatorname{ReLU}(z)=\max(0,z)
$$

它把负数置为 `0`，正数原样保留。`nn.ReLU()` 没有要学习的参数，却改变了网络能表示的函数族。实践中它计算简单，正半轴梯度稳定，所以经常作为隐藏层默认起点。

| 激活函数 | 输出特征 | 常见位置 | 需要留意的边界 |
| -------- | -------- | -------- | -------------- |
| `ReLU` | 非负，正数不压缩 | 隐藏层 | 长期落在负区时可能输出恒为 0 |
| `LeakyReLU` | 负区保留小斜率 | 隐藏层、图像网络 | 负半轴斜率是额外超参数或可学习参数 |
| `Sigmoid` | `(0, 1)` | 二分类概率解释 | 大正/负值处容易饱和，训练损失通常不手写它 |
| `Tanh` | `(-1, 1)` | 某些循环网络或特定值域 | 同样可能饱和 |

“激活”不表示模型突然理解了什么；它表示一个确定的非线性函数。这个名称本身不值得被神秘化。

## 输出层不是随意接一个激活函数

隐藏层激活函数用于表达能力；**输出层的形式由任务和损失函数共同决定**。最容易出错的地方，恰恰是把它们混为一谈。

| 任务 | 模型最后通常输出 | 训练时常用损失 | 评估/展示时的转换 |
| ---- | ---------------- | -------------- | ----------------- |
| 回归 | 一个或多个实数 | `MSELoss`、`L1Loss` | 通常不加激活；按目标值域决定 |
| 二分类 | 一个 logit | `BCEWithLogitsLoss` | `sigmoid(logit)` 得到正类概率 |
| 单标签多分类 | 每类一个 logit `[B, C]` | `CrossEntropyLoss` | `softmax` 得到各类概率，`argmax` 取类别 |
| 多标签分类 | 每类一个独立 logit `[B, C]` | `BCEWithLogitsLoss` | 对每一类分别 `sigmoid` 与阈值判断 |

**logit** 是尚未转成概率的原始分数。二分类中，一个 logit 足够：正数倾向类别 `1`，负数倾向类别 `0`。将 sigmoid 写进模型末尾并再使用 `BCEWithLogitsLoss`，会让 sigmoid 被计算两次；多分类中先 `softmax` 再交给 `CrossEntropyLoss` 也是同类错误。下一篇会从损失函数角度解释原因。

## 两种写法：`nn.Sequential` 与自定义 `nn.Module`

层严格按顺序连接时，`nn.Sequential` 最短：

```python
from torch import nn

model = nn.Sequential(
    nn.Linear(2, 8),
    nn.ReLU(),
    nn.Linear(8, 1),
)
```

每次调用 `model(features)`，PyTorch 依次调用三个模块，得到一个形状为 `[B, 1]` 的 logit。`nn.Sequential` 适合教学和简单直线式网络；它的局限也正来自“只能顺序连接”。有多个输入、残差分支或中间结果需要复用时，应定义自己的 `nn.Module`：

```python
import torch
from torch import nn


class BinaryClassifier(nn.Module):
    def __init__(self) -> None:
        super().__init__()
        self.hidden = nn.Linear(2, 8)
        self.activation = nn.ReLU()
        self.output = nn.Linear(8, 1)

    def forward(self, features: torch.Tensor) -> torch.Tensor:
        hidden = self.activation(self.hidden(features))
        return self.output(hidden).squeeze(1)


model = BinaryClassifier()
logits = model(torch.randn(4, 2))
print(logits.shape)  # torch.Size([4])
```

必须分清三个角色：

- `__init__()`：创建并登记层；赋给 `self.hidden` 的 `nn.Linear` 才会成为模型的子模块，其参数才能被优化器发现；
- `forward()`：定义一批输入如何流向输出；通常调用 `model(x)`，而非在业务代码中直接调用 `model.forward(x)`，因为前者会保留 PyTorch 的钩子与模块调用机制；
- `super().__init__()`：初始化 `nn.Module` 的内部登记结构；漏掉它，子模块和参数不能被可靠追踪。

这段模型仍然没有学习任何东西。它只定义了“给定参数时如何计算预测”的前向路径；损失、反向传播与优化器才会让参数发生变化。

## 常见误解与检查顺序

1. **层数更多一定更强。** 不一定。网络容量、数据量、优化是否稳定和任务难度必须匹配；更多层还可能过拟合或更难训练。
2. **每层都必须用同一种激活函数。** 不需要。隐藏层和输出层的职责不同，选择应服从任务的输出语义与损失函数契约。
3. **`nn.Linear(2, 8)` 的 8 是 batch 大小。** 不是。它是每条样本生成的隐藏特征数；batch 大小来自输入第一维。
4. **调用模型就会学习。** 不会。`model(x)` 只执行前向传播；只有后续的 `backward()` 与 `optimizer.step()` 才会改变参数。

读网络代码时，先写下每层的输入和输出 shape，再问它是否有可学习参数、激活函数作用在哪个维度。这样的顺序比从类名猜“它大概很高级”可靠得多。

## 小结

- 神经网络是可学习函数的组合；线性层通过权重和偏置将输入变为输出。
- 线性层连续叠加仍是线性变换，隐藏层中的激活函数提供必要的非线性表达能力。
- `nn.Linear` 的参数表示每条样本的特征维和输出维，不表示 batch 大小；始终用 shape 验证理解。
- 输出层、损失函数和标签格式必须作为一个整体设计。下一篇将解释这一组契约怎样把“错了多少”精确传给模型。
