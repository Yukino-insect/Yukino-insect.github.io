RAG 评测的目的不是证明系统“看起来不错”，而是回答一个更严格的问题：某次改动到底让哪些问题变好了，哪些问题变差了，代价是什么。

这一章把评测拆成数据集、指标、运行流程和报告分析。没有评测的 RAG 优化，很容易变成调参占卜。听上去玄妙，结果通常也很玄妙。

## 学习目标

- 能设计基础评测集和黄金证据。
- 能区分检索、生成和系统性能指标。
- 能理解 RAGAS 一类自动评测工具的适用边界。
- 能输出一份可指导优化的评测报告。
