很多 PyTorch 示例都可以压缩成几行：准备张量，调用模型，计算 `loss`，再写 `loss.backward()` 和 `optimizer.step()`。能运行当然是一个开始，但若不知道每一行改变了什么，换一个数据集、损失函数或报错信息，程序就会立刻变成不可解释的仪式。

本课程只补齐**能够简单使用 PyTorch**所需的理论地基，不试图替代完整的数学、统计学习或深度学习教材。读完后，你应能读懂一个最小训练脚本，知道模型从什么数据学、为何不能拿测试集反复调参、为什么损失会驱动参数更新，以及该从哪里排查“训练了却没有学会”。至于大规模分布式训练、Transformer 细节和模型部署，它们有各自的专题，没有必要在这里提前制造负担。

## 学习目标与边界

课程以二分类和小型全连接网络为例。它们足够小，因而可以把数据、形状、梯度和参数更新全部看清；同一套训练逻辑仍适用于图像分类、文本分类和回归任务。模型结构会变化，以下骨架并不会：

```text
训练数据
  → 前向计算得到预测
  → 损失衡量预测与标签的差距
  → 反向传播计算参数梯度
  → 优化器更新参数
  → 用未参与更新的数据检查泛化能力
```

本课程假定你会基本 Python，并能在虚拟环境中安装 PyTorch。没有 GPU 也可以完成所有实验；示例数据和模型刻意很小，CPU 足够。GPU、混合精度、批处理与显存问题请在后续的[模型推理与重排序课程](../02-model-inference-and-rerank/00-overview.md)中学习。

## 阅读顺序

1. [机器学习的任务、数据与泛化](01-machine-learning-data-and-generalization.md)：确定输入、标签、训练集、验证集、测试集和指标分别承担什么职责。
2. [张量、矩阵计算与导数](02-tensor-linear-algebra-and-gradients.md)：理解 `shape`、矩阵乘法、广播和梯度，不再把张量只看作“一个数组”。
3. [神经网络如何训练](03-neural-network-training-loop.md)：用一段可运行代码串起 `forward → loss → backward → step`，再认识学习率、batch 和过拟合。

## 环境与运行方式

若尚未安装 PyTorch，请先在独立环境中执行：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install torch
python -c "import torch; print(torch.__version__)"
```

最后一条命令能输出版本号，就足以运行本课。首次需要 CUDA 时，不要随便复制旧版本命令；应根据本机平台和显卡，使用 [PyTorch 官方安装页面](https://pytorch.org/get-started/locally/) 给出的当前组合。框架会更新，记忆里的安装命令却不会；把两者混为一谈，通常只会得到一段很有教育意义的报错。

## 小结

- PyTorch 是表达和执行数值计算、自动求导与参数优化的工具；它不会替你定义正确的问题或准备可信的数据。
- 能简单训练模型，至少要同时理解数据划分、张量形状、损失、梯度和优化器五件事。
- 本课程优先建立可验证的直觉；每段代码都应能回答“输入是什么、输出是什么、这一步为何需要”。
