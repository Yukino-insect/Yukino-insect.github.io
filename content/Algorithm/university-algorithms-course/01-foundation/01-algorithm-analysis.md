复杂度不是给代码贴一个 `O(n log n)` 标签。它描述的是：当输入规模 $n$ 增大时，算法完成所需基本操作数和额外存储量如何增长。考研中常见的陷阱，是只数循环层数，却没有看见内层循环的边界在变化。

## 一、先确定规模与基本操作

设输入规模为 $n$。对查找问题，基本操作通常是关键字比较；对排序问题，常分别统计比较和移动；对图算法，规模通常有顶点数 $V$ 与边数 $E$。先说清楚在数什么，结论才有意义。

渐近记号忽略常数与低阶项：

$$
T(n)=3n^2+7n+2=O(n^2)
$$

这并不表示常数不重要；在同一台机器、相近规模上常数会影响速度。它只是说，当 $n$ 足够大时，二次项决定增长趋势。

## 二、三种常用推导方式

### 1. 顺序语句相加，嵌套循环相乘

下面程序读入 `n` 个整数并统计所有下标对。`count++` 执行次数为 $n(n-1)/2$，因此时间复杂度为 $O(n^2)$；除读入数组外没有随 $n$ 增长的工作区，算法额外空间为 $O(1)$。

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int& x : a) cin >> x;

    long long pairs = 0;
    for (int i = 0; i < n; ++i) {
        for (int j = i + 1; j < n; ++j) {
            ++pairs;
        }
    }
    cout << pairs << '\n';
}
```

注意内层不是恰好运行 $n$ 次。它运行 $n-1,n-2,\ldots,0$ 次，和为等差数列。考题若把 `j = i + 1` 换为 `j = 2 * i`，机械地写“二重循环所以 $O(n^2)$”就会出错。

### 2. 每轮按比例缩小，使用对数

二分查找每一次比较都把候选区间至少缩小一半。经过 $k$ 次后，规模约为 $n/2^k$；令它降到 1，得到 $k=\log_2 n$。循环变量不是每次加一时，应该从“规模缩小了多少倍”而不是从循环层数思考。

### 3. 递归写成递推式

归并排序把规模为 $n$ 的问题拆成两个 $n/2$，再线性合并：

$$
T(n)=2T(n/2)+O(n)=O(n\log n)
$$

递归树有 $\log n$ 层，每层合并总代价为 $O(n)$。递归调用栈深度为 $O(\log n)$，但归并所用临时数组为 $O(n)$，所以总辅助空间是 $O(n)$，不能只报栈深度。

## 三、可运行示例：二分查找与循环不变量

程序返回有序数组中第一个不小于 `target` 的位置；若所有元素都小于目标，返回 `n`。循环不变量是：答案若存在，一直位于闭开区间 `[left, right)` 内。使用这个不变量，`left < right`、`right = mid` 与 `left = mid + 1` 都自然得出。

```cpp
#include <iostream>
#include <vector>
using namespace std;

int lowerBound(const vector<int>& a, int target) {
    int left = 0, right = static_cast<int>(a.size());
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (a[mid] >= target) right = mid;
        else left = mid + 1;
    }
    return left;
}

int main() {
    int n, target;
    cin >> n >> target;
    vector<int> a(n);
    for (int& x : a) cin >> x;
    cout << lowerBound(a, target) << '\n';
}
```

例如输入 `6 4` 和 `1 2 4 4 7 9`，输出为 `2`。每轮区间长度至少减半，时间为 $O(\log n)$；只使用常数个变量，辅助空间为 $O(1)$。

## 四、空间复杂度到底是否包含输入

课程与考研中通常报告的是**辅助空间**：算法为计算额外申请的空间。上例传入的数组是输入，不计为算法额外空间；若函数内部复制整个数组，复制才是 $O(n)$。递归空间要统计最大同时存活的调用帧，而不是调用总次数。

## 五、考研检查清单

- 循环条件是加法增长、乘法增长，还是依赖外层变量？
- 递归式中有几棵子树，每层工作量是多少？
- 最好、最坏、平均情况是否不同？二分查找的比较次数就依目标位置而变。
- 明确写“辅助空间”，并把递归栈、数组、队列、哈希表逐项相加。

复杂度分析的目标不是制造更漂亮的符号，而是在写程序前判断方案是否会在规模增长时失控。这个判断，比一段看似正确的代码更早决定了算法是否合格。
