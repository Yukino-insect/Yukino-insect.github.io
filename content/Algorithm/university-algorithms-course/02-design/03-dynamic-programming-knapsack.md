动态规划适合具有**最优子结构**和**重叠子问题**的问题。它不是“写一个二维数组”这么简单：状态必须准确说明“已经考虑了什么、还剩什么约束”，转移必须穷尽最后一步的互斥选择。

0/1 背包的描述是：有 `n` 件物品，第 `i` 件重量为 `weight[i]`、价值为 `value[i]`；容量为 `capacity` 的背包中，每件物品至多选一次，求最大总价值。这是考研中状态定义、递推与空间压缩的典型题。

## 一、先写状态，再写转移

定义 `dp[i][c]` 为“只考虑前 `i` 件物品（下标 `0` 到 `i-1`），背包容量不超过 `c` 时的最大价值”。第 `i` 件物品在这个状态中还未被考虑，避免了下标混乱。

对第 `i` 件物品（代码下标为 `i - 1`）只有两种互斥情况：

- 不选它：最大价值为 `dp[i - 1][c]`。
- 选择它：仅当 `weight[i - 1] <= c`，价值为 `dp[i - 1][c - weight[i - 1]] + value[i - 1]`。

因此取两者较大值。边界 `dp[0][c] = 0` 表示没有物品时无法获得价值，`dp[i][0] = 0` 表示容量为零时无法装入正重量物品。

## 二、为什么可以压缩为一维

转移只依赖上一层 `i - 1`，所以可让 `dp[c]` 原地保存当前层的结果。但容量必须**从大到小**遍历：这样更新 `dp[c]` 时读取的 `dp[c - weight]` 仍是上一件物品留下的值，确保同一物品不会被重复选。

若改为从小到大更新，`dp[c - weight]` 可能已在本轮加入过当前物品，语义会悄悄变成“完全背包”。这不是小小的编码风格问题，而是状态依赖方向改变了。

## 三、完整 C++17 程序

输入第一行 `n capacity`，之后 `n` 行每行 `weight value`。输出可取得的最大价值。

```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n, capacity;
    cin >> n >> capacity;
    vector<int> weight(n), value(n);
    for (int i = 0; i < n; ++i) {
        cin >> weight[i] >> value[i];
    }

    vector<int> dp(capacity + 1, 0);
    for (int i = 0; i < n; ++i) {
        for (int c = capacity; c >= weight[i]; --c) {
            dp[c] = max(dp[c], dp[c - weight[i]] + value[i]);
        }
    }

    cout << dp[capacity] << '\n';
}
```

例如输入：

```text
3 4
2 3
1 2
3 4
```

输出为 `6`，对应选择第 1、2 件物品。容量没有必要被恰好装满；`dp[c]` 的含义是“不超过 `c`”，而不是“正好等于 `c`”。

## 四、正确性：最后一件物品的完备分类

考虑前 `i` 件物品、容量 `c` 的任意最优解。它要么不包含第 `i` 件物品，要么包含它，二者不可能同时成立也不会遗漏。前者的最优价值不超过 `dp[i-1][c]`；后者去除该物品后，剩余解不超过 `dp[i-1][c-weight[i-1]]`，加上该物品价值就是第二个候选值。递推取最大值，因此得到最优解。按 `i` 归纳，算法正确。

一维实现的倒序循环保证读取的是“上一层”状态，所以它计算的结果与二维递推完全一致。

## 五、时间、空间与适用边界

外层遍历 `n` 件物品，内层最多扫描 `capacity` 个容量，时间复杂度为 `O(n * capacity)`。这不是关于输入位数的多项式时间：当容量用二进制编码且很大时，它属于伪多项式算法。二维表的辅助空间是 `O(n * capacity)`；上面的滚动数组为 `O(capacity)`。

若题目要求恢复选了哪些物品，一维数组不足以直接回溯，应保留二维决策信息，或额外记录选择。若物品可无限次选，改为容量从小到大遍历；这条方向正是 0/1 背包与完全背包最常见、也最容易失分的分界线。

## 六、考研答题模板

- 先写出状态的两个维度和精确语义。
- 写清不选、选取两个分支及其合法条件。
- 给出初始值，说明循环顺序。
- 最后报告 `O(n * capacity)` 时间与相应空间，且说明能否压缩。

动态规划并不是把指数枚举“神奇地变快”。它只是发现大量不同决策路径会抵达同一状态，于是每个状态只求一次。状态设计正确，转移才有资格正确。
