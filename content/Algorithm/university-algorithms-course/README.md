这是一套面向本科“算法设计”课程、并与考研数据结构考点衔接的系列文章。它不把算法当成一串等待背诵的模板，而是把每一种方法放回它要解决的问题中：输入规模是什么，候选解怎样表示，如何证明算法正确，以及代价为何是这个复杂度。

所有程序均使用 **C++17**，给出完整的 `main` 函数，可以用下列命令编译。示例输入会写在相应章节中；自己改动数据再运行，比只看输出可靠得多。

```bash
g++ -std=c++17 -O2 -Wall chapter.cpp -o chapter
./chapter
```

## 二、每章应当学会什么

每章都遵循同一条链：**问题模型 → 数据表示 → 算法不变量或状态 → C++ 实现 → 正确性理由 → 时间与空间复杂度 → 考试易错点**。

阅读代码时请先回答三个问题：循环或递归的“不变量”是什么；每一步让问题规模如何变化；额外空间在何处申请、何时释放。若这三个问题答不出，即使样例通过，也还谈不上掌握。

## 三、与考研数据结构如何配合

考研数据结构通常不只问“会不会写”。选择题和填空题会让你判断存储结构、比较次数、递归深度和渐近界；算法题则要求你在明确的数据结构约束下写出可执行步骤。因此每章的复习可以分两轮：

- 第一轮：手画小规模输入，跟踪指针、下标、队列或 `dp` 表的变化。
- 第二轮：脱离代码写出状态定义、边界条件、循环不变量和复杂度推导，再回头实现。

课程不会替代教材中的概念定义，但会把这些定义落实为程序。比如“邻接表的空间复杂度是 `O(V+E)`”不是一条结论，而是顶点表加上每条边恰好存一次或两次所得到的计数。

## 四、建议的练习节奏

每学习一章，至少完成下面四件事：

1. 不看代码复述算法输入、输出和核心不变量。
2. 用三个边界数据测试：空/最小规模、重复或相等元素、极端有序或不连通情形。
3. 改写一个条件，例如把“求值”改成“求位置”，或把无向图改成有向图。
4. 写出最好、最坏和常见情况下的复杂度；若无法区分，说明你还没有看清分支条件。

学算法不需要把自己训练成背诵机器。能说明“为什么这里必须保留等号”“为什么这张表要倒序更新”，才算真正拥有了它。
