平衡树是考研数据结构中“定义不难、推导很容易失手”的典型。普通二叉搜索树（BST）若按 `1, 2, 3, 4, 5` 插入，会退化为一条链，查找、插入和删除都可能变为 `O(n)`。AVL 树要求每个结点左右子树高度之差不超过 `1`，用局部旋转把树高稳定在 `O(log n)`。

本文只讨论最常考的 AVL 插入调整。删除同样依赖旋转，但失衡点和旋转后向上继续检查的情形更复杂；先把插入的四种型别真正看懂，比过早背下删除流程可靠得多。

## 一、前置条件：BST 性质与平衡因子

二叉搜索树满足：左子树键值小于根，右子树键值大于根，左右子树也分别满足同一规则。中序遍历 BST 会得到递增序列。

设空树高度为 `0`、叶子高度为 `1`，则结点 `x` 的平衡因子为：

```text
BF(x) = height(x.left) - height(x.right)
```

AVL 树要求每个结点的 `BF` 都在 `-1、0、1` 中。插入一个新结点后，从插入路径向上，第一个出现 `|BF| = 2` 的祖先就是需要调整的最低失衡结点。考试画图时，先圈出它，再看“新结点落在重路径的左边还是右边”；不要只凭结点值大小猜旋转，这种做法相当不可靠。

## 二、四种失衡型别

| 型别 | 插入路径 | 修复动作 | 例子 |
| ---- | -------- | -------- | ---- |
| LL | 失衡结点左孩子的左侧 | 对失衡结点右旋 | `30, 20, 10` |
| RR | 失衡结点右孩子的右侧 | 对失衡结点左旋 | `10, 20, 30` |
| LR | 失衡结点左孩子的右侧 | 先左旋左孩子，再右旋失衡结点 | `30, 10, 20` |
| RL | 失衡结点右孩子的左侧 | 先右旋右孩子，再左旋失衡结点 | `10, 30, 20` |

以 LL 为例，`30` 的左链为 `30 -> 20 -> 10`。对 `30` 右旋后，`20` 升为局部根，`10` 在左、`30` 在右；中序序列仍是 `10, 20, 30`，所以 BST 有序性没有被破坏。RR 是完全对称的情形。LR 和 RL 的第一步是把“折线”拉直，第二步才等价于一次单旋。

## 三、可直接运行的 C++17 插入实现

下面程序插入一组会同时触发 LL、RR、LR、RL 检查路径的键，并输出中序遍历和每个结点的高度。保存为 `avl.cpp` 后执行 `g++ -std=c++17 avl.cpp -o avl` 即可运行。

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

struct Node {
    int key;
    int height = 1;
    Node* left = nullptr;
    Node* right = nullptr;

    explicit Node(int value) : key(value) {}
};

int height(const Node* node) {
    return node == nullptr ? 0 : node->height;
}

int balanceFactor(const Node* node) {
    return node == nullptr ? 0 : height(node->left) - height(node->right);
}

void updateHeight(Node* node) {
    node->height = 1 + std::max(height(node->left), height(node->right));
}

//        y                 x
//       / \               / \
//      x   T3   ->      T1  y
//     / \                   / \
//    T1 T2                 T2 T3
Node* rotateRight(Node* y) {
    Node* x = y->left;
    Node* t2 = x->right;

    x->right = y;
    y->left = t2;
    updateHeight(y);  // 子树更低的结点先更新
    updateHeight(x);
    return x;
}

Node* rotateLeft(Node* x) {
    Node* y = x->right;
    Node* t2 = y->left;

    y->left = x;
    x->right = t2;
    updateHeight(x);
    updateHeight(y);
    return y;
}

Node* insert(Node* root, int key) {
    if (root == nullptr) {
        return new Node(key);
    }

    if (key < root->key) {
        root->left = insert(root->left, key);
    } else if (key > root->key) {
        root->right = insert(root->right, key);
    } else {
        return root;  // 本实现不重复保存相同键
    }

    updateHeight(root);
    const int bf = balanceFactor(root);

    if (bf > 1 && key < root->left->key) {       // LL
        return rotateRight(root);
    }
    if (bf < -1 && key > root->right->key) {     // RR
        return rotateLeft(root);
    }
    if (bf > 1 && key > root->left->key) {       // LR
        root->left = rotateLeft(root->left);
        return rotateRight(root);
    }
    if (bf < -1 && key < root->right->key) {     // RL
        root->right = rotateRight(root->right);
        return rotateLeft(root);
    }

    return root;
}

void printInOrder(const Node* root) {
    if (root == nullptr) {
        return;
    }
    printInOrder(root->left);
    std::cout << root->key << "(h=" << root->height << ") ";
    printInOrder(root->right);
}

void destroy(Node* root) {
    if (root == nullptr) {
        return;
    }
    destroy(root->left);
    destroy(root->right);
    delete root;
}

int main() {
    Node* root = nullptr;
    const std::vector<int> keys{30, 10, 20, 40, 50, 25, 5};

    for (int key : keys) {
        root = insert(root, key);  // 注意接住旋转后的新子树根
    }

    printInOrder(root);
    std::cout << "\nroot = " << root->key
              << ", height = " << root->height << '\n';
    destroy(root);
}
```

代码中最关键的不是四个 `if` 本身，而是两个返回值：旋转会改变局部子树的根，因此 `insert` 必须返回新根，父结点要写成 `root->left = insert(...)` 或 `root->right = insert(...)`。旋转后也必须先更新下沉结点的高度，再更新上升结点；顺序倒过来会把旧高度带入计算。

## 四、复杂度与常见比较

AVL 树高度是 `O(log n)`，查找、插入、删除的最坏时间复杂度也都是 `O(log n)`；一次插入最多通过常数次旋转修复最低失衡结点，递归栈空间为 `O(log n)`。旋转不是重新排序整棵树，只重接常数条边，所以旋转本身是 `O(1)`。

| 结构 | 平衡约束 | 查找最坏复杂度 | 常见特点 |
| ---- | -------- | -------------- | -------- |
| 普通 BST | 无 | `O(n)` | 有序，但可能退化 |
| AVL 树 | 任意结点高度差至多 1 | `O(log n)` | 平衡严格，查找稳定 |
| 红黑树 | 黑高等颜色规则 | `O(log n)` | 调整较少，工程库常用 |
| B/B+ 树 | 多路、所有叶子同层 | `O(log_m n)` | 降低磁盘 I/O，常用于数据库索引 |

不要把 AVL、红黑树和 B+ 树当成可以互相替换的三个术语：它们都追求“树高不失控”，但平衡条件、分支数以及面向内存还是磁盘的设计目标不同。

## 五、考场检查清单

- 求平衡因子时统一空树高度定义；不要在同一道题里一会儿把空树当 `0`，一会儿当 `-1`。
- 先找最低失衡结点，再依据插入路径判定 LL、RR、LR、RL。
- 单旋后检查中序序列是否仍递增；这能迅速发现子树接错位置。
- AVL 的“平衡”不等于完全二叉树，更不要求左右子树节点数相等。
- 若题目要求删除，要从实际删除位置向根回溯检查；一次删除可能使多个祖先失衡。

AVL 题真正考的是不变量：BST 的键序必须保留，所有结点的高度信息必须正确，所有结点的平衡因子必须落在允许范围内。把这三件事逐项核对，旋转图就不再需要靠记忆碰运气。
