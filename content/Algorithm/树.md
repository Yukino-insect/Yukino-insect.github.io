树是一种层级结构，常用于表示文件目录、组织结构、语法树、索引结构和各种搜索问题。

## 一、基本概念

树由节点和边组成。最上层节点叫根节点，没有子节点的节点叫叶子节点。

常见概念如下：

1. 父节点：当前节点的上一层节点。
2. 子节点：当前节点的下一层节点。
3. 兄弟节点：拥有同一个父节点的节点。
4. 深度：从根节点到当前节点经过的边数。
5. 高度：从当前节点到最远叶子节点经过的边数。

深度是自顶向下看，高度是自底向上算。

## 二、二叉树

二叉树是每个节点最多有两个子节点的树。两个子节点通常称为左子节点和右子节点。

常见二叉树类型包括：

1. 满二叉树：每一层节点都满。
2. 完全二叉树：除了最后一层，其余层都满，最后一层从左到右连续。
3. 二叉搜索树：左子树小于根节点，右子树大于根节点。
4. 平衡二叉树：在搜索树基础上控制高度差。

## 三、树的遍历

二叉树常见遍历方式有：

1. 前序遍历：根、左、右。
2. 中序遍历：左、根、右。
3. 后序遍历：左、右、根。
4. 层序遍历：按层从左到右。

二叉搜索树的中序遍历结果是有序的，这是很多算法题的关键。

## 四、求树的高度

如果把空树高度定义为 `-1`，叶子节点高度就是 `0`：

```java
int height(TreeNode root) {
    if (root == null) {
        return -1;
    }
    int left = height(root.left);
    int right = height(root.right);
    return Math.max(left, right) + 1;
}
```

这个递归会先算左右子树高度，再回到当前节点，因此是自底向上计算。

## 五、总结

树类问题通常离不开递归。理解每个节点要向父节点返回什么信息，比记忆模板更重要。
