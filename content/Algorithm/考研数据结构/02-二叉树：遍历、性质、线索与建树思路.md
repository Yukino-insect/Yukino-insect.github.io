树题的失分往往不是因为不会画树，而是把“遍历序列”“树的形态”“二叉搜索树”混成同一件事。二叉树规定每个结点至多两个孩子，左、右子树有位置区别；二叉搜索树是在二叉树之上额外加入键值次序约束。前者决定遍历方式，后者才让中序遍历有序。

## 一、四种基本遍历与访问时机

设当前根为 `root`：

| 遍历 | 访问根的时机 | 典型用途 |
| ---- | ------------ | -------- |
| 先序 | 左右子树之前 | 复制树、前缀表达式 |
| 中序 | 左子树之后、右子树之前 | BST 得到递增序列 |
| 后序 | 左右子树之后 | 释放树、后缀表达式、计算高度 |
| 层序 | 按层从左到右 | 判断层次、最短边数、完全二叉树检查 |

先序加中序、或后序加中序，在结点值互异时能唯一确定一棵二叉树；仅有先序和后序一般不能唯一确定，因为某个结点只有一个孩子时，无法看出它是左孩子还是右孩子。

## 二、需要会推导的性质

设二叉树中度为 `0、1、2` 的结点数分别为 `n0、n1、n2`。树的边数一方面等于结点数减一，即 `n0 + n1 + n2 - 1`；另一方面，每个度为 1、2 的结点分别贡献 1、2 条边，即 `n1 + 2n2`。两式相等得到：

```text
n0 = n2 + 1
```

这是任意非空二叉树的性质，不要求是满二叉树或完全二叉树。另一个高频概念是完全二叉树：除最后一层外各层都满，最后一层结点从左到右连续排列。含 `n` 个结点的完全二叉树，若根的数组下标为 `1`，结点 `i` 的左右孩子下标分别为 `2i`、`2i + 1`，父结点为 `floor(i / 2)`。

## 三、可运行的遍历程序

递归遍历的代码短，但考试也常要求非递归中序和层序。下面程序同时给出它们，并用后序释放动态结点。编译命令为 `g++ -std=c++17 tree.cpp -o tree`。

```cpp
#include <iostream>
#include <queue>
#include <stack>

struct Node {
    char value;
    Node* left = nullptr;
    Node* right = nullptr;

    explicit Node(char value) : value(value) {}
};

void preOrder(const Node* root) {
    if (root == nullptr) return;
    std::cout << root->value << ' ';
    preOrder(root->left);
    preOrder(root->right);
}

void inOrderIterative(const Node* root) {
    std::stack<const Node*> st;
    const Node* current = root;

    while (current != nullptr || !st.empty()) {
        while (current != nullptr) {
            st.push(current);
            current = current->left;
        }
        current = st.top();
        st.pop();
        std::cout << current->value << ' ';
        current = current->right;
    }
}

void levelOrder(const Node* root) {
    if (root == nullptr) return;
    std::queue<const Node*> q;
    q.push(root);

    while (!q.empty()) {
        const Node* current = q.front();
        q.pop();
        std::cout << current->value << ' ';
        if (current->left != nullptr) q.push(current->left);
        if (current->right != nullptr) q.push(current->right);
    }
}

void destroy(Node* root) {
    if (root == nullptr) return;
    destroy(root->left);
    destroy(root->right);
    delete root;
}

int main() {
    //        A
    //      /   \
    //     B     C
    //    / \     \
    //   D   E     F
    Node* root = new Node('A');
    root->left = new Node('B');
    root->right = new Node('C');
    root->left->left = new Node('D');
    root->left->right = new Node('E');
    root->right->right = new Node('F');

    preOrder(root);          // A B D E C F
    std::cout << '\n';
    inOrderIterative(root);  // D B E A C F
    std::cout << '\n';
    levelOrder(root);        // A B C D E F
    std::cout << '\n';
    destroy(root);
}
```

非递归中序的含义是：沿左链不断入栈；左边走到空后，弹出一个最近未访问的祖先；访问它后转向右子树，再重复同一过程。栈并不是为了让代码显得复杂，它精确保存了递归调用本来会保存的返回位置。

## 四、线索二叉树与哈夫曼树的定位

普通二叉链表中，含有 `n` 个结点的二叉树一共有 `n + 1` 个空指针域。线索二叉树利用这些空指针，记录某种遍历下的前驱或后继，从而在不使用栈和递归的情况下按该遍历顺序访问结点。线索必须说明是先序、中序还是后序；“后继”永远相对于指定的遍历序列而言。

哈夫曼树则是带权路径长度（WPL）最小的二叉树。构造时反复选择当前权值最小的两棵树合并；它不要求叶子按原顺序排列，也没有度为 1 的结点。哈夫曼编码的前缀性质来自叶子只出现在编码树末端，而不是因为代码表恰好长得整齐。

## 五、复习检查清单

- 中序遍历有序只能推出“它是一棵 BST 的遍历结果”，前提是结点键值按 BST 规则定义；普通二叉树没有这个结论。
- 空树高度、叶子高度、树的层数在不同教材可能有不同起点，计算前先写定义。
- 层序遍历用队列；深度优先的递归/显式模拟通常用栈。不要把两种容器位置颠倒。
- `n0 = n2 + 1` 与 `n1` 无关，推导时不要凭直觉补上额外条件。

树题的关键是把“访问顺序”“结点关系”和“附加约束”分层处理。先确定题目到底问的是遍历、构造、性质还是编码，再选择对应的工具，答案会清晰得多。
