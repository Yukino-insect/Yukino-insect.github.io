图把“线性后继”和“树形父子”都放宽为任意顶点之间的边，因此考题的第一步永远是确认：这是有向图还是无向图？边是否带权？是否允许负权？是否保证连通或无环？没有这些前提，DFS、拓扑排序和 Dijkstra 很容易被写成看似熟悉、实际不成立的答案。

## 一、存储结构与复杂度

邻接矩阵用 `V × V` 表记录边，判断两点是否相邻为 `O(1)`，但空间为 `O(V^2)`；邻接表为每个顶点保存出边表，空间为 `O(V + E)`，遍历整张图为 `O(V + E)`，适合稀疏图。

无向图的一条边在邻接表中通常要存两次；有向图的入度与出度不同，邻接表默认方便得到出度，若需要频繁求入度可额外维护入度数组或建立逆邻接表。

## 二、四个高频算法的边界

| 算法 | 核心容器/思想 | 解决什么问题 | 关键前提 |
| ---- | ------------- | ------------ | -------- |
| DFS | 递归或显式栈 | 连通性、路径、环检测基础 | 非连通图要从每个未访问顶点再次启动 |
| BFS | 队列 | 无权图最少边数路径 | 首次访问时标记并入队 |
| 拓扑排序 | 入度 + 队列 | 有向无环图的先后依赖 | 有向图；输出数少于顶点数说明有环 |
| Dijkstra | 贪心 + 最小堆 | 单源非负权最短路 | 所有边权必须非负 |

无权图中 BFS 才能保证按最少边数逐层抵达；DFS 找到一条路径并不代表它最短。Dijkstra 一旦遇到负边，已经“确定”的距离可能被后来负边改小，贪心依据被破坏，应改用 Bellman-Ford 等算法。

## 三、可运行的邻接表、BFS、拓扑排序与 Dijkstra

程序使用一个带权有向图。忽略权值时可看作 BFS/拓扑排序的普通有向边；所有权值均为非负，故 Dijkstra 可用。

```cpp
#include <functional>
#include <iostream>
#include <limits>
#include <queue>
#include <utility>
#include <vector>

struct Edge {
    int to;
    int weight;
};

using Graph = std::vector<std::vector<Edge>>;

std::vector<int> bfs(const Graph& graph, int start) {
    std::vector<bool> visited(graph.size(), false);
    std::vector<int> order;
    std::queue<int> q;
    visited[start] = true;
    q.push(start);

    while (!q.empty()) {
        const int u = q.front();
        q.pop();
        order.push_back(u);
        for (const Edge& edge : graph[u]) {
            if (!visited[edge.to]) {
                visited[edge.to] = true;  // 入队时标记，防止重复入队
                q.push(edge.to);
            }
        }
    }
    return order;
}

std::vector<int> topologicalSort(const Graph& graph) {
    std::vector<int> inDegree(graph.size(), 0);
    for (const auto& edges : graph) {
        for (const Edge& edge : edges) {
            ++inDegree[edge.to];
        }
    }

    std::queue<int> q;
    for (int v = 0; v < static_cast<int>(graph.size()); ++v) {
        if (inDegree[v] == 0) q.push(v);
    }

    std::vector<int> order;
    while (!q.empty()) {
        const int u = q.front();
        q.pop();
        order.push_back(u);
        for (const Edge& edge : graph[u]) {
            if (--inDegree[edge.to] == 0) q.push(edge.to);
        }
    }
    return order;  // size 小于顶点数时，图存在有向环
}

std::vector<int> dijkstra(const Graph& graph, int start) {
    constexpr int inf = std::numeric_limits<int>::max() / 4;
    std::vector<int> distance(graph.size(), inf);
    using State = std::pair<int, int>;  // {当前距离, 顶点}
    std::priority_queue<State, std::vector<State>, std::greater<State>> minHeap;

    distance[start] = 0;
    minHeap.push({0, start});
    while (!minHeap.empty()) {
        const auto [dist, u] = minHeap.top();
        minHeap.pop();
        if (dist != distance[u]) continue;  // 跳过旧的堆条目

        for (const Edge& edge : graph[u]) {
            if (distance[edge.to] > dist + edge.weight) {
                distance[edge.to] = dist + edge.weight;
                minHeap.push({distance[edge.to], edge.to});
            }
        }
    }
    return distance;
}

int main() {
    Graph graph(6);
    auto addEdge = [&](int from, int to, int weight) {
        graph[from].push_back({to, weight});
    };
    addEdge(0, 1, 2); addEdge(0, 2, 5); addEdge(1, 3, 1);
    addEdge(2, 3, 2); addEdge(3, 4, 3); addEdge(4, 5, 1);

    for (int v : bfs(graph, 0)) std::cout << v << ' ';
    std::cout << '\n';
    const std::vector<int> topo = topologicalSort(graph);
    std::cout << "DAG: " << (topo.size() == graph.size()) << '\n';
    const std::vector<int> distance = dijkstra(graph, 0);
    std::cout << "distance(0, 5) = " << distance[5] << '\n';  // 7
}
```

二叉堆优化的 Dijkstra 复杂度为 `O((V + E) log V)`。堆中同一顶点可存在旧距离条目，这不是错误；弹出时用 `dist != distance[u]` 跳过旧条目即可。若采用邻接矩阵并每轮线性选最小未确定点，复杂度通常为 `O(V^2)`，稠密图时反而并不吃亏。

## 四、考场易错点

- DFS/BFS 的外层循环不可省略，除非题目已保证从起点可达所有顶点。
- Kahn 拓扑排序中，队列初始装入的是**所有**入度为 `0` 的顶点；不同入队顺序可能得到不同但都正确的拓扑序。
- 拓扑序存在当且仅当有向图无环；无向图的“无环”叫森林，不能直接谈拓扑序。
- 最小生成树连接所有顶点且总边权最小，最短路径最小化的是两个顶点间路径长度；Prim、Kruskal 与 Dijkstra 的贪心目标不同，不能互换。

图算法的名称很多，底层原则却很明确：先写清图模型与约束，再选择保证仍然成立的算法。题干少看一个“负权”或“有向”，整道题的结论就可能已经换了。
