查找和排序题的难点常常藏在条件里：二分查找要求数据已经有序；快速排序平均很快却可能退化；稳定性由“相等元素是否保持相对次序”决定，和算法名字是否听起来温和没有关系。复习时应把算法的循环不变式、边界和复杂度一起记，而不是只背一张表。

## 一、二分查找：区间约定决定边界

下面使用半开区间 `[left, right)`：`left` 包含、`right` 不包含。循环不变式是“若目标存在，它一定仍在当前区间内”。当 `values[mid] < target` 时，`mid` 及其左侧都可排除，所以 `left = mid + 1`；否则保留 `mid`，令 `right = mid`。循环结束时 `left` 就是第一个不小于目标的位置，即 lower bound。

```cpp
#include <cstddef>
#include <iostream>
#include <vector>

std::size_t lowerBound(const std::vector<int>& values, int target) {
    std::size_t left = 0;
    std::size_t right = values.size();

    while (left < right) {
        const std::size_t mid = left + (right - left) / 2;
        if (values[mid] < target) {
            left = mid + 1;
        } else {
            right = mid;
        }
    }
    return left;
}

int main() {
    const std::vector<int> values{1, 2, 2, 2, 5, 9};
    const std::size_t pos = lowerBound(values, 2);
    std::cout << pos << '\n';  // 1：第一个 2 的位置
}
```

二分查找时间是 `O(log n)`，但前提是序列按比较规则有序；对链表也不合适，因为即便确定了中间逻辑位置，到达它仍要 `O(n)` 走指针。计算中点写成 `left + (right - left) / 2` 可以避免 `left + right` 的整型溢出。

## 二、归并与快排：同为分治，代价不同

归并排序把序列递归分成两半，排序后线性合并，任何输入下时间都为 `O(n log n)`，代价是需要 `O(n)` 辅助数组。只要合并时相等元素优先取左半部分，它就是稳定排序。

快速排序选择一个枢轴并划分小于、等于、大于枢轴的区域，平均 `O(n log n)`，原地实现的额外空间通常来自递归栈；若枢轴持续选到最小或最大值，最坏可到 `O(n^2)`。三路划分对大量重复键尤其友好。

下面程序实现稳定归并排序和三路快速排序，均可直接运行：

```cpp
#include <algorithm>
#include <iostream>
#include <random>
#include <vector>

void mergeSort(std::vector<int>& values, std::vector<int>& buffer,
               int left, int right) {
    if (right - left <= 1) return;
    const int mid = left + (right - left) / 2;
    mergeSort(values, buffer, left, mid);
    mergeSort(values, buffer, mid, right);

    int i = left;
    int j = mid;
    int k = left;
    while (i < mid && j < right) {
        if (values[i] <= values[j]) {  // 相等时先取左侧，保持稳定性
            buffer[k++] = values[i++];
        } else {
            buffer[k++] = values[j++];
        }
    }
    while (i < mid) buffer[k++] = values[i++];
    while (j < right) buffer[k++] = values[j++];
    for (int index = left; index < right; ++index) values[index] = buffer[index];
}

void quickSort(std::vector<int>& values, int left, int right) {
    if (left >= right) return;
    const int pivot = values[left + (right - left) / 2];
    int less = left;
    int current = left;
    int greater = right;

    while (current <= greater) {
        if (values[current] < pivot) {
            std::swap(values[less++], values[current++]);
        } else if (values[current] > pivot) {
            std::swap(values[current], values[greater--]);
        } else {
            ++current;
        }
    }
    quickSort(values, left, less - 1);
    quickSort(values, greater + 1, right);
}

int main() {
    std::vector<int> first{5, 2, 5, 1, 9, 2, 3};
    std::vector<int> buffer(first.size());
    mergeSort(first, buffer, 0, static_cast<int>(first.size()));

    std::vector<int> second{5, 2, 5, 1, 9, 2, 3};
    quickSort(second, 0, static_cast<int>(second.size()) - 1);

    for (int value : first) std::cout << value << ' ';
    std::cout << '\n';
    for (int value : second) std::cout << value << ' ';
    std::cout << '\n';
}
```

## 三、常见排序算法比较

| 算法 | 最好 | 平均 | 最坏 | 额外空间 | 稳定性 |
| ---- | ---- | ---- | ---- | -------- | ------ |
| 直接插入排序 | `O(n)` | `O(n^2)` | `O(n^2)` | `O(1)` | 稳定 |
| 冒泡排序 | `O(n)`（有提前结束） | `O(n^2)` | `O(n^2)` | `O(1)` | 稳定 |
| 选择排序 | `O(n^2)` | `O(n^2)` | `O(n^2)` | `O(1)` | 通常不稳定 |
| 归并排序 | `O(n log n)` | `O(n log n)` | `O(n log n)` | `O(n)` | 稳定 |
| 快速排序 | `O(n log n)` | `O(n log n)` | `O(n^2)` | 递归栈 | 通常不稳定 |
| 堆排序 | `O(n log n)` | `O(n log n)` | `O(n log n)` | `O(1)` | 不稳定 |

稳定性只有在“记录含相同排序键”时才有可观察意义。例如按分数排序学生，若分数相同还希望保持原来班级录入顺序，就需要稳定排序或额外的次关键字。对单纯整数数组谈稳定性没有错，但你看不出差别。

## 四、典型误区

- 二分的 `mid` 命中目标并不总该立刻返回；寻找第一个/最后一个目标时，仍要继续收缩一侧边界。
- 快排每次划分后，递归区间必须排除已经放入正确区域的部分；区间不缩小会无限递归。
- “平均复杂度更好”不等于对任何输入更快；近乎有序的数据上插入排序可能很优秀。
- 堆排序的建堆可在 `O(n)` 完成，不是对每个元素都做一次 `O(log n)` 插入后就必须得出的 `O(n log n)`；两种建堆方式不同。

查找与排序题的核心不是背结论，而是维护区间、划分和相对顺序这些不变量。只要每一步都能说明“排除了什么、保留了什么”，边界题就不会再靠运气通过。
