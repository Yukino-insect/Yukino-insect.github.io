存储器扩展题真正要解决的不是“把几片芯片画在一起”，而是让 CPU 在每次访问中只找到**唯一正确的一个存储单元**。地址线负责说明“访问哪一个字”，数据线负责搬运这一字的各位，读写控制线负责说明方向，片选信号则负责说明“究竟由哪一片芯片响应”。把这四件事分开，`2K×4`、`2K×8`、位扩展、字扩展和 74LS138 便不再是一堆容易互相干扰的名词。

本文以一个便于手工画图的**16 位地址总线、8 位数据总线** CPU 为例，设计 `8K×8` RAM 与 `8K×8` ROM：RAM 映射到 `0000H–1FFFH`，ROM 映射到 `8000H–9FFFH`。CPU 的具体型号不同，读写信号名和有效电平可能不同；只要按本文的逻辑替换，连线方法不变。关于地址线数、字节编址和数据总线宽度的基础，可先阅读[《16 位地址总线能寻址多少内存：字节编址、字编址与数据总线的区别》](../01-data-representation/16位地址总线能寻址多少内存：字节编址、字编址与数据总线的区别.md)。

## 一、先读懂芯片容量：`2K×8` 到底表示什么

存储芯片容量一般写成：

```text
字数 × 每个字的位数
```

因此：

| 芯片规格 | 可存储的字数 | 每字宽度 | 需要的片内地址线 | 总容量 |
| --- | ---: | ---: | ---: | ---: |
| `2K×4` | $2\times1024=2^{11}$ | 4 位 | 11 根 | 8 Kbit = 1 KiB |
| `2K×8` | $2^{11}$ | 8 位 | 11 根 | 16 Kbit = 2 KiB |
| `8K×8` | $2^{13}$ | 8 位 | 13 根 | 64 Kbit = 8 KiB |

`K` 在这种容量标记中通常表示 $1024=2^{10}$，不是十进制的 1000。一个 `2K×8` 芯片内部有 $2^{11}$ 个地址，所以芯片必须有 `A0` 到 `A10` 共 11 根**片内地址输入线**；每个地址取出 8 位，因此有 `I/O0` 到 `I/O7` 八根数据引脚。

不要把“字数”和“字节数”混为一谈。`2K×8` 的一个字正好是 8 位，所以总容量是 `2K` 字节；`2K×4` 的一个字只有半个字节，因而总容量只有 `1 KiB`。

## 二、一片 SRAM/ROM 在图上有哪些关键引脚

不同厂商芯片的物理脚号不完全相同，接线时必须以所用芯片数据手册为准；但是信号职责通常如下。

| 信号 | `2K×8` SRAM 的典型含义 | ROM 的典型含义 | 应接到哪里 |
| --- | --- | --- |
| `A0–A10` | 选择芯片内部 2K 个单元之一 | 同左 | CPU 的低 11 位地址线 |
| `I/O0–I/O7` 或 `D0–D7` | 双向数据线 | 只输出数据 | CPU 的 `D0–D7` 数据总线 |
| `/CE` 或 `/CS` | 低有效片选，决定芯片是否响应 | 同左 | 74LS138 的低有效输出 |
| `/OE` | 低有效输出使能，允许芯片向数据总线驱动数据 | 同左 | CPU 的低有效读控制 `/RD` |
| `/WE` | 低有效写使能，允许 SRAM 写入 | ROM 通常没有；可编程 ROM 另有编程控制 | CPU 的低有效写控制 `/WR`；ROM 禁止写 |
| `VCC`、`GND` | 电源 | 电源 | 电源和地 |

斜杠 `/` 或名称末尾的 `#` 表示**低有效**。例如 `/CE=0` 才是选中，`/WE=0` 才是写入。低有效不是附注，而是决定 74LS138 能否直接相连的关键信息。

### 1. CPU 数据总线与 SRAM 数据脚为何可以直接并联

多片芯片的 `I/O0–I/O7` 都可以分别接在公共 `D0–D7` 总线上：所有芯片的 `I/O0` 接 `D0`，依此类推。读周期里，只有 `/CE=0` 且 `/OE=0` 的被选中芯片会输出数据，其余芯片处于高阻态，像是从总线上断开；写周期里，CPU 驱动数据总线，只有 `/CE=0` 且 `/WE=0` 的 SRAM 接收数据。

若片选设计错误，同时让两片 ROM 或 RAM 输出不同数据，便会发生**总线争用**：两个输出级彼此对抗，轻则读数错误，重则超过芯片允许电流。片选必须保证“一次读操作至多一个输出者”，并不是为了让图纸看上去复杂一点。

## 三、位扩展与字扩展：只看哪一维不够，就扩哪一维

这两个概念最容易混淆，但其实只是在扩充容量表达式的两个方向。

```text
              每字位数（数据宽度）
                    ↑ 位扩展
字数（地址深度） → 存储器规格
                    ↑ 字扩展
```

### 1. 位扩展：地址相同，数据位并排

若有两片 `2K×4` SRAM，要组成一片逻辑上的 `2K×8` RAM：

- 两片的 `A0–A10` 分别并联到 CPU 的 `A0–A10`；
- 两片的 `/CE` 同接一个片选信号；
- 两片的 `/OE` 同接 `/RD`，两片的 `/WE` 同接 `/WR`；
- 低四位芯片的 `I/O0–I/O3` 接 CPU `D0–D3`；
- 高四位芯片的 `I/O0–I/O3` 接 CPU `D4–D7`。

此时 CPU 给出某个地址，例如 `A10…A0=00000000101`，两片芯片都会访问各自第 5 个单元；前者交出低 4 位，后者交出高 4 位，合起来就是一个 8 位数据。**位扩展增加每个字有多少位，不增加可选地址数**。

同理，两片 `2K×8` 并排可得到 `2K×16`：低字节芯片接 `D0–D7`，高字节芯片接 `D8–D15`，地址与控制线仍完全共享。

### 2. 字扩展：数据总线共用，高位地址决定选哪一片

若有四片 `2K×8` SRAM，要组成 `8K×8` RAM：

- 四片均把 `A0–A10` 接 CPU `A0–A10`；
- 四片均把 `I/O0–I/O7` 接公共数据总线 `D0–D7`；
- 四片均把 `/OE` 接 `/RD`，均把 `/WE` 接 `/WR`；
- CPU 的额外地址位 `A11`、`A12` 经过译码器，分别产生四根独立的低有效 `/CE0–/CE3`，各接一片芯片的 `/CE`。

因为 $8K=2^{13}$ 而每片只有 $2K=2^{11}$ 个字，所以多出来的两位 `A11`、`A12` 恰好可以区分 $2^2=4$ 片。**字扩展增加可选地址数，不增加每个字的数据位数**。

四片的地址范围可写为：

| `A12 A11` | 被选中的 `2K×8` 芯片 | 在一个 8K 块中的偏移地址 |
| --- | --- | --- |
| `00` | 第 0 片 | `0000H–07FFH` |
| `01` | 第 1 片 | `0800H–0FFFH` |
| `10` | 第 2 片 | `1000H–17FFH` |
| `11` | 第 3 片 | `1800H–1FFFH` |

注意表中没有列出 `A0–A10`，因为它们进入每一片芯片内部，继续选择该片的 2048 个单元。

### 3. 同时扩展：先分组，再选组

例如要用 `2K×4` 芯片做出 `8K×8` RAM，需要 $4\times2=8$ 片：

1. 每两片先做一次**位扩展**，成为一组 `2K×8`：一片接 `D0–D3`，另一片接 `D4–D7`，两片共享地址和控制线。
2. 再准备四个这样的组，用 `A11`、`A12` 做**字扩展**：同一组内两片的 `/CE` 接同一个译码输出，不同组接不同输出。

因此，芯片数量可以先用一个简单公式核对：

$$
\text{所需芯片数}
=\frac{\text{目标字数}}{\text{单片字数}}
\times
\frac{\text{目标位数}}{\text{单片位数}}.
$$

对 `8K×8` 与 `2K×4`，即：

$$
\frac{8K}{2K}\times\frac84=4\times2=8.
$$

## 四、74LS138 为什么特别适合做片选

74LS138（常简称 74138）是一个**3 线—8 线译码器/分配器**。它有三根选择输入 `A、B、C`，在被使能时，八根输出 `/Y0–/Y7` 中恰有一根为低电平，其余为高电平。

常用逻辑关系如下：

| `C B A` | 低电平输出 |
| --- | --- |
| `000` | `/Y0` |
| `001` | `/Y1` |
| `010` | `/Y2` |
| `011` | `/Y3` |
| `100` | `/Y4` |
| `101` | `/Y5` |
| `110` | `/Y6` |
| `111` | `/Y7` |

`A` 是最低位选择输入，`C` 是最高位。芯片还必须满足下列使能条件才工作：

```text
G1    = 1       （高有效使能）
/G2A  = 0       （低有效使能）
/G2B  = 0       （低有效使能）
```

输出低有效，刚好能直接接大多数 SRAM/ROM 的低有效 `/CE`。这就是它在存储器扩展题中如此常见的原因。

若实验要求标出 74LS138 的物理脚号，标准 16 脚 DIP 封装通常为：`A=1`、`B=2`、`C=3`、`/G2A=4`、`/G2B=5`、`G1=6`、`/Y7=7`、`GND=8`、`/Y6=9`、`/Y5=10`、`/Y4=11`、`/Y3=12`、`/Y2=13`、`/Y1=14`、`/Y0=15`、`VCC=16`。实际连线前仍应核对手中器件的丝印和数据手册；把逻辑名对上比凭脚号记忆可靠得多。

## 五、完整设计：16 位地址 CPU 连接 `8K×8` RAM 与 `8K×8` ROM

现在给出一套可以直接画成电路图的方案。假定：

- CPU 地址总线为 `A15–A0`，按字节编址；
- CPU 数据总线为 `D7–D0`；
- `/MREQ` 表示低有效“存储器周期有效”；`/RD` 表示低有效读；`/WR` 表示低有效写；
- RAM 用四片 `2K×8` SRAM：`RAM0–RAM3`；
- ROM 用四片 `2K×8` ROM：`ROM0–ROM3`；
- 需要三片 74LS138：一级地址译码器 `U1`，RAM 片内组选器 `U2`，ROM 片内组选器 `U3`。

如果题目没有给出 `/MREQ`，可以把它理解为“CPU 正在访问存储器”的有效信号；最小模型中可令 `U1` 始终使能，但这样无法区分 I/O 周期，正式设计不建议省略。

### 1. 先规定地址空间，不规定它就无法判断片选对错

| 设备 | 逻辑容量 | CPU 地址范围 | 高三位 `A15 A14 A13` |
| --- | ---: | --- | --- |
| RAM | `8K×8` | `0000H–1FFFH` | `000` |
| ROM | `8K×8` | `8000H–9FFFH` | `100` |

一个 `8K` 块占 $2^{13}=8192=2000H$ 个连续字节。故 `0000H+2000H-1=1FFFH`；ROM 同理从 `8000H` 延续到 `9FFFH`。将最高三位完整译码，才能保证 RAM 和 ROM 不会在其他地址产生镜像。

### 2. 一级 74LS138 `U1`：用高位地址选 8K 大块

按下列方式连接 `U1`：

```text
U1.A       <- CPU A13
U1.B       <- CPU A14
U1.C       <- CPU A15
U1.G1      <- 逻辑 1（VCC）
U1./G2A    <- CPU /MREQ
U1./G2B    <- 逻辑 0（GND）
```

于是，在存储器周期中：

- 当 `A15 A14 A13=000`，`U1./Y0=0`，表示选中 RAM 所在的 `0000H–1FFFH` 大块；
- 当 `A15 A14 A13=100`，`U1./Y4=0`，表示选中 ROM 所在的 `8000H–9FFFH` 大块；
- 其余 `/Y1–/Y3`、`/Y5–/Y7` 暂不使用，均可留作其他存储器或 I/O 的地址空间。

不要把 `U1./Y0` 直接接给四片 RAM 的 `/CE`。那会让四片同时选中，读时四片同时向同一总线输出，写时四片同时收到同一数据。`U1` 只完成“哪一个 8K 大块”的选择，还需要 `U2` 在块内选具体 2K 芯片。

### 3. RAM 的二级 74LS138 `U2`：用 `A12、A11` 选四片 RAM

连接 `U2`：

```text
U2.A       <- CPU A11
U2.B       <- CPU A12
U2.C       <- 逻辑 0（GND）
U2.G1      <- 逻辑 1（VCC）
U2./G2A    <- U1./Y0
U2./G2B    <- 逻辑 0（GND）

U2./Y0     -> RAM0./CE
U2./Y1     -> RAM1./CE
U2./Y2     -> RAM2./CE
U2./Y3     -> RAM3./CE
```

`U1./Y0` 低电平时，`U2` 才被允许工作，因此 `U2` 只会在 RAM 的 8K 大块内产生低有效片选。又因为 `U2.C=0`，只有 `/Y0–/Y3` 可能有效；`A12 A11` 的四种组合恰好选择四片 RAM：

| CPU 地址范围 | `A12 A11` | 低有效片选 | 响应芯片 |
| --- | --- | --- | --- |
| `0000H–07FFH` | `00` | `U2./Y0` | `RAM0` |
| `0800H–0FFFH` | `01` | `U2./Y1` | `RAM1` |
| `1000H–17FFH` | `10` | `U2./Y2` | `RAM2` |
| `1800H–1FFFH` | `11` | `U2./Y3` | `RAM3` |

### 4. ROM 的二级 74LS138 `U3`：接法相同，只是总使能改为 `/Y4`

连接 `U3`：

```text
U3.A       <- CPU A11
U3.B       <- CPU A12
U3.C       <- 逻辑 0（GND）
U3.G1      <- 逻辑 1（VCC）
U3./G2A    <- U1./Y4
U3./G2B    <- 逻辑 0（GND）

U3./Y0     -> ROM0./CE
U3./Y1     -> ROM1./CE
U3./Y2     -> ROM2./CE
U3./Y3     -> ROM3./CE
```

相应的 ROM 地址为：

| CPU 地址范围 | 低有效片选 | 响应芯片 |
| --- | --- | --- |
| `8000H–87FFH` | `U3./Y0` | `ROM0` |
| `8800H–8FFFH` | `U3./Y1` | `ROM1` |
| `9000H–97FFH` | `U3./Y2` | `ROM2` |
| `9800H–9FFFH` | `U3./Y3` | `ROM3` |

### 5. 八片存储芯片共同的地址、数据和控制连线

以下连接不因芯片属于 RAM 或 ROM 而改变：

```text
RAM0–RAM3.A0–A10  <- CPU A0–A10（同名线逐根并联）
ROM0–ROM3.A0–A10  <- CPU A0–A10（同名线逐根并联）

RAM0–RAM3.I/O0–I/O7 <-> CPU D0–D7（同名线逐根并联）
ROM0–ROM3.D0–D7    -> CPU D0–D7（同名线逐根并联）

RAM0–RAM3./OE     <- CPU /RD
RAM0–RAM3./WE     <- CPU /WR
ROM0–ROM3./OE     <- CPU /RD
```

ROM 若带普通 `/WE` 引脚，必须固定为高电平，防止运行期间误写；真正只读 ROM 没有这个输入。RAM 的 `/OE` 与 `/WE` 在典型 CPU 时序下分别由 `/RD` 与 `/WR` 控制，二者不会同时有效。若题目给出的 SRAM 是高有效 `CE`、`OE` 或 `WE`，则需要增加反相器，或者选用 74LS138 的反相信号后再推导；不能因为名称相似就硬连。

下面的文字图概括了层次关系：

```text
CPU A15..A13 ──> U1（8K 块译码）
                    ├─ /Y0 ──> U2（RAM 内部 2K 片选） ──> RAM0..RAM3 /CE
                    └─ /Y4 ──> U3（ROM 内部 2K 片选） ──> ROM0..ROM3 /CE

CPU A12,A11 ──────> U2、U3 的选择输入
CPU A10..A0 ──────> 每一片存储芯片的片内地址输入
CPU D7..D0  <─────> 所有对应的数据 I/O 引脚
CPU /RD,/WR ──────> 输出使能、RAM 写使能
```

## 六、一次读和一次写在这张图上如何发生

画完线后，最好用一个具体地址逐拍检查。这样能迅速发现“多片同时选中”或“地址位接错”的问题。

### 1. 读取 `1234H`：应从 `RAM2` 取得数据

`1234H` 的关键地址位为：

```text
A15 A14 A13 = 000  -> U1./Y0 变低，RAM 大块有效
A12 A11     = 10   -> U2./Y2 变低，RAM2 被选中
A10..A0     = 234H -> RAM2 内部选择偏移为 234H 的单元
```

CPU 令 `/MREQ=0`、`/RD=0`、`/WR=1`。`RAM2` 的 `/CE` 与 `/OE` 均有效，因而把该单元的 8 位数据驱动到 `D7–D0`；其他 RAM 芯片没有被选中，ROM 译码器也未被使能。CPU 在规定时刻采样数据后撤销 `/RD`，RAM2 输出回到高阻态。

### 2. 写入 `0A5CH`：应只写入 `RAM1`

```text
A15 A14 A13 = 000  -> RAM 大块有效
A12 A11     = 01   -> U2./Y1 变低，RAM1 被选中
A10..A0     = 25CH -> RAM1 内部偏移 25CH
```

CPU 先在 `D7–D0` 放好待写数据，再令 `/MREQ=0`、`/RD=1`、`/WR=0`。只有 `RAM1` 同时满足 `/CE=0`、`/WE=0`，在写时序要求的边沿或电平窗口把数据存入内部单元。ROM 没有有效写使能，即使其数据线也并在总线上也不会被改写。

### 3. 读取 `9234H`：应从 `ROM2` 取得指令或常量

```text
A15 A14 A13 = 100  -> U1./Y4 变低，ROM 大块有效
A12 A11     = 10   -> U3./Y2 变低，ROM2 被选中
A10..A0     = 234H -> ROM2 内部偏移 234H
```

读信号使 `ROM2./OE=0`，ROM2 输出数据。写信号即使被误送到系统，也不会通过普通 ROM 改变内容；如果实际使用 Flash/EEPROM，编程模式还需满足专用命令、时序和写保护条件，不能把它当作普通 SRAM。

## 七、常见错误，以及如何用地址位数自检

### 1. 把所有地址线都接进每片 `2K×8`

一片 `2K×8` 只有 11 根片内地址输入，只应接 `A0–A10`。`A11` 以上的 CPU 地址位不是“多余不用”，而是用来选择哪一片芯片、哪一个大地址块。把高位随意接到芯片的低位地址脚，会使地址错位而不是扩容。

### 2. 字扩展时把四片 `/CE` 并在一起

位扩展中并联 `/CE` 是正确的，因为同一地址的多片要一起拼出更多数据位；字扩展中并联 `/CE` 则是错误的，因为不同芯片代表不同地址段。判断方法只有一句：**它们是在共同组成同一个字，还是在分别保存不同地址的字？** 前者共享片选，后者必须独立片选。

### 3. 忘记 74LS138 输出为低有效

`/Y0` 被选中时是 `0`，这正适合接 `/CE`。若所用存储器的 `CE` 是高有效，必须取反；否则地址匹配时芯片反而被禁用。画图时最好在每个低有效信号上保留横线、`/` 或 `#`，不要只写模糊的 `CS`。

### 4. 只译码部分高位地址，造成地址镜像

若只用 `A11、A12` 选择四片 RAM，却完全不检查 `A13–A15`，同一组 RAM 会在 64K 地址空间的多个位置重复出现。例如本应只在 `0000H–1FFFH` 的 RAM 还可能在 `2000H–3FFFH`、`4000H–5FFFH` 等范围被访问。这叫**地址镜像**。有些简化实验故意允许它以节省器件，但题目若要求指定 RAM/ROM 地址范围，就应完整译码高位地址。

### 5. 忘记存储器周期与 I/O 周期的区分

若 CPU 有独立 I/O 地址空间，`/MREQ` 或等价的 `M/IO` 信号应参与 `U1` 的使能。否则 CPU 对 I/O 端口的访问可能意外选中 RAM/ROM。没有该信号的教学模型可暂时忽略这一层，但应明确这是模型简化，而不是片选本身不需要时序条件。

### 6. 16 位 CPU 不一定意味着要把每片都接成 16 位

本文假设 CPU 数据总线就是 8 位。若 CPU 有 `D15–D0`，而目标是 `8K×16`，可将每个 `2K` 深度组中的两片 `2K×8` 做位扩展：一片接低字节 `D7–D0`，一片接高字节 `D15–D8`，两片共享同一个 `/CE`。然后仍由 `A11、A12` 在四个深度组之间作字扩展，共需 8 片 `2K×8`。

8086 这类“16 位数据总线但按字节编址”的处理器还会用 `A0` 与 `/BHE` 选择低/高字节存储体，细节与这里的普通位扩展不同，可参见[《8086 为什么把内存分为奇偶存储体：16 位数据总线、A0 与 BHE》](../01-data-representation/8086为什么把内存分为奇偶存储体：16位数据总线、A0与BHE.md)。不要在未确认 CPU 总线规则前，把该机制照搬到所有 16 位 CPU 上。

## 八、从题目到电路图的固定解题流程

以后面对任意“用若干存储芯片和 74138 扩展 RAM/ROM”的题，可以按此顺序落笔：

1. 写出目标容量和单片容量，分别计算深度倍数、位宽倍数与总芯片数。
2. 由单片字数 $2^m$ 确定片内地址线 `A0–A(m-1)`；由目标深度 $2^n$ 找出剩余 $n-m$ 根地址位用于芯片选择。
3. 先做位扩展：同一组芯片共享地址、控制和片选，分别承接不同数据位。
4. 再做字扩展：不同深度组共享片内低地址与数据总线，但必须各有独立片选。
5. 规定 RAM、ROM 的 CPU 地址范围，用更高位地址和 74LS138 完整译码出设备级片选。
6. 核对有效电平：74LS138 的 `/Y`、存储器的 `/CE`、`/OE`、`/WE` 与 CPU 控制线是否同为低有效；不同则加反相。
7. 任选一个读地址和一个写地址，逐位追踪“高位选块、中位选片、低位选单元、数据线方向”，确认每次只有一片会驱动或写入。

存储器扩展的核心可以压缩为一句话：**低位地址进芯片选单元，数据线按位宽并排，高位地址经译码器选芯片，读写控制线决定数据方向。** 只要每一根线都能回答这四个问题中的一个，电路图即使尚未画出，也已经具有可验证的结构了。
