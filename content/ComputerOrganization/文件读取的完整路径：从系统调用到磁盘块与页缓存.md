## 一、从用户态进入内核

应用程序调用语言库提供的 `read`、`fread` 或更高层 API。库函数最终会准备文件描述符、用户缓冲区地址和长度，并执行系统调用指令进入内核。

```text
用户程序
  -> read(fd, buffer, length)
  -> 系统调用入口
  -> 内核检查参数和权限
```

文件描述符不是磁盘地址。它通常只是当前进程文件描述符表中的一个小整数，内核通过它找到打开文件对象，再找到对应的 inode、文件偏移和挂载点。

## 二、打开文件时发生了什么

`open` 阶段通常已经完成了路径解析：

1. 从根目录或当前工作目录开始查找路径分量；
2. 查询目录项缓存，必要时读取目录块；
3. 找到文件元数据并检查权限、类型和挂载选项；
4. 创建或复用打开文件对象；
5. 为进程分配文件描述符。

之后的 `read(fd, ...)` 不必再次解析完整路径，只需沿着文件描述符找到打开文件对象。

## 三、先查页缓存

现代操作系统通常把普通文件内容缓存为内存中的页。读取时，内核先检查所需文件偏移对应的页是否已经在页缓存中：

```text
read 请求
  -> 页缓存命中：直接从内核页复制到用户缓冲区
  -> 页缓存未命中：提交块 I/O，等待数据进入页缓存
```

页缓存的单位通常与虚拟内存页相近，但“文件偏移”与“进程虚拟地址”仍是两种不同坐标。文件页缓存中的一页可以被多个进程通过 `read` 或 `mmap` 共享使用。

## 四、缓存未命中时如何定位磁盘

当目标文件页不在页缓存中，文件系统根据文件元数据把文件偏移转换成设备逻辑块号，再构造块 I/O 请求。请求会经过块层队列和设备驱动：

```text
文件偏移
  -> 文件逻辑块
  -> 设备逻辑块
  -> 块层请求队列
  -> NVMe/SATA/USB 驱动
  -> 控制器与磁盘介质
```

机械硬盘还涉及磁头定位和旋转等待；SSD 则由闪存转换层把逻辑块映射到闪存页和擦除块。操作系统通常只看到统一的逻辑块设备接口，不直接管理 NAND 芯片的每个物理单元。

## 五、DMA 与完成通知

现代设备常使用 DMA，让控制器直接把数据写入内核准备好的内存缓冲区，而不是让 CPU 逐字节搬运。设备完成请求后，通过中断或轮询通知内核。

完成路径大致是：

```text
设备把数据写入 DMA 缓冲区
  -> 控制器报告完成
  -> 内核处理中断或完成队列
  -> 标记页缓存页有效
  -> 唤醒等待 I/O 的线程
```

关于设备提交与完成队列，可以结合[操作系统 I/O 接口是什么：系统调用、设备驱动与提交完成队列](操作系统 I_O 接口是什么：系统调用、设备驱动与提交完成队列.md)阅读。

## 六、从页缓存到用户缓冲区

普通 `read` 通常还需要把数据从内核可管理的页缓存复制到用户提供的缓冲区。这样做可以保持内核与用户地址空间的保护边界。

```text
磁盘数据
  -> 内核页缓存
  -> copy_to_user
  -> 用户虚拟地址
```

如果使用 `mmap`，进程可以把文件页直接映射进自己的虚拟地址空间。第一次访问映射区域时可能触发缺页异常，内核再把文件页调入并建立页表映射。`mmap` 减少了显式复制，但仍然需要页缓存、权限检查和缺页处理。

## 七、为什么第二次读取更快

第一次读取可能包含设备 I/O；完成后，文件页留在页缓存中。第二次读取若仍然命中缓存，就不必访问磁盘，只需要进行内存访问和必要的用户空间复制。

这也解释了“文件很小但第一次打开很慢、第二次很快”的现象。缓存命中并不表示文件已经永久加载到 RAM；内存紧张时，干净的文件页可以被回收，之后再访问仍可从文件重新读取。

## 八、读取不是“直接找文件地址”

一次 `read` 至少涉及四种地址或标识：

| 名称 | 含义 |
| ---- | ---- |
| 文件描述符 | 进程用来引用打开文件对象的整数 |
| 文件偏移 | 文件内容中的逻辑位置 |
| 设备逻辑块号 | 块设备接口使用的位置 |
| 物理地址/虚拟地址 | 内存中缓存和用户缓冲区的位置 |

把这些概念混为“文件地址”会遗漏大量关键步骤。文件系统负责文件偏移到设备块的转换，内存管理负责缓存页和用户地址的映射，设备驱动负责把块请求变成硬件操作。

## 九、总结

- `open` 解析路径并创建打开文件对象，`read` 主要通过文件描述符继续操作。
- 文件系统把文件偏移转换为设备逻辑块，块层和驱动再提交硬件 I/O。
- 页缓存让后续读取可以直接从 RAM 返回。
- DMA、完成队列和中断减少了 CPU 搬运数据的工作。
- `read` 通常涉及一次从内核页缓存到用户缓冲区的复制，`mmap` 则通过页表和缺页机制访问文件页。
