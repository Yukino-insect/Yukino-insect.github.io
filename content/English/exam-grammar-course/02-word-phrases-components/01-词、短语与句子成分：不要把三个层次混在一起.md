“这个词是什么词性”“这个短语作什么成分”“这个从句修饰谁”是三个不同层次的问题。它们常被一起问，于是也常被一起弄乱。一个词的词性说的是它本身有什么语法能力；短语说的是若干词组合成了什么单位；句子成分则说该单位在整句中承担什么职责。先把这三层分开，许多看似古怪的排列就会恢复秩序。

## 词性：词本身能做什么

英语常见开放词类包括名词、动词、形容词、副词；常见功能词包括冠词和其他限定词、代词、介词、连词、助动词等。同一个拼写可属于不同词性，必须结合位置判断。

| 词类 | 常见作用 | 例子 |
| ---- | -------- | ---- |
| 名词 | 指人、物、概念，可作名词短语核心 | `idea`, `development` |
| 动词 | 表动作、过程、状态 | `change`, `seem` |
| 形容词 | 描述名词或作表语 | `useful`, `economic` |
| 副词 | 修饰动词、形容词、副词或整个句子 | `carefully`, `very`, `probably` |
| 介词 | 建立名词性成分与其他成分的关系 | `of`, `in`, `with` |
| 连词/关系词 | 连接分句，标出逻辑或关系 | `because`, `that`, `which` |

例如 `fast` 可以是形容词（`a fast train`），也可以是副词（`run fast`）；`like` 可以是动词“喜欢”，也可以是介词“像”。词典给出的多个词性不是故意添乱，而是提醒你：词义要先服从句法位置。

## 短语：围绕一个中心词形成的单位

短语不一定很长。`the new policy`、`very carefully`、`in the city` 都是短语，因为内部有一个中心词，并带着自己的修饰或限定。

```text
名词短语 NP：the surprisingly effective new policy
                └──────── policy 是中心名词

动词短语 VP：may have changed rapidly
                └──────── changed 是主要动作，其他词说明语气、时间、方式

介词短语 PP：in a highly competitive market
                └──────── in 是介词；后面的名词短语是介词宾语
```

形容词短语（`very useful`）与副词短语（`quite slowly`）也一样。短语整体可在句中行动，不必把其中每个词都分别硬塞进句子成分表。

## 句子成分：这个单位在整句中做什么

同一个词或短语的内部类别并不自动决定它在句中的位置。名词短语最常作主语、宾语、表语；介词短语可作定语、状语或补足语；从句也可以承担名词、形容词或副词性职责。

```text
The book on the desk belongs to Maria.
```

`on the desk` 是介词短语，但它修饰 `book`，因此在句中作后置定语：“桌上的那本书”。

```text
Maria studies on the desk every morning.
```

同样的 `on the desk` 说明 `studies` 发生的地点，作状语：“玛丽亚每天早晨在书桌旁学习”。词性没有变，句法功能变了；判断关键是它回答了“哪本书”，还是“在哪里学习”。

## 主、谓、宾、表、定、状、补的分工

| 成分 | 要回答的问题 | 示例 |
| ---- | ------------ | ---- |
| 主语 | 谁/什么是话题或动作发出者？ | `The result` surprised us. |
| 谓语 | 主语怎样、做什么、是什么？ | The result `seems` reliable. |
| 宾语 | 动作作用于谁/什么？ | We checked `the result`. |
| 表语 | 主语是什么/怎样？ | The result is `reliable`. |
| 定语 | 哪一个、什么样的？ | the `reliable` result |
| 状语 | 何时、何地、怎样、为何、在何条件下？ | checked it `carefully` |
| 补语 | 主语或宾语最后是什么/怎样？ | found the result `reliable` |

补语很容易和状语混淆。`They left the door open.` 中 `open` 说明宾语 `the door` 的状态，删去它会改变“让门保持开着”的关键意思，故为宾补。`They left quietly.` 中 `quietly` 只说明离开的方式，故为状语。一个简便测试是：该成分能否和主语/宾语形成“是……/变成……”关系？能，往往就是补语。

## 副词为什么常在句尾

副词并不都以 `-ly` 结尾，`fast`、`hard`、`late` 都可作副词；而 `friendly`、`likely` 虽有 `-ly`，却常是形容词。更重要的是，副词的位置受到种类与信息重点影响，不能靠“看见句尾就以为它不修饰什么”。

```text
She spoke very clearly yesterday.
```

`very` 修饰副词 `clearly`，`clearly` 修饰动词 `spoke`，`yesterday` 作时间状语。英语常把方式、地点、时间等较长的状语放在句末，所以句尾的成分尤其要问：它是在说明动作、整个判断，还是前面的名词？

## 两个名词连续出现时

英语允许一个名词放在另一个名词前作定语：`language learning`, `data analysis`, `school library`。后一个通常是中心名词，前一个说明类别、用途、材料或内容：

```text
a history teacher      # 教历史的老师，不是“有历史的老师”
a coffee cup           # 装咖啡的杯子，不一定由咖啡制成
```

这不是两个名词无规则地碰在一起，而是一个压缩的名词短语。需要注意语义关系没有单一公式：`stone wall` 是材料，`office worker` 是工作场所/类别，`summer holiday` 是时间。看中心名词和语境，而不是给前一个名词机械地补“的”。

## 小结

- 词性、短语类型、句子成分分别回答“它是什么”“它和谁组成单位”“它在整句做什么”。
- 介词短语、非谓语短语和从句都可能作多种成分，必须看依附对象和语义问题。
- 副词在句尾并不罕见；位置不能代替功能判断。
- 连续名词中，后一个多为中心名词，前一个通常起分类性定语作用。
