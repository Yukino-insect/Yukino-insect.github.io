动词是英语句子的发动机，但它并不总以“一个动词 = 一个谓语”的方式出现。助动词、情态动词、进行和完成形式会组成动词短语；`to do`、`doing`、`done` 又能离开谓语位置，去充当名词、定语、状语或补语。再加上并非只有 `be` 才能连接主语与表语，很多初学阶段形成的规则需要升级，而不是被推翻。

## 谓语动词组：把一组词看成一个中心

```text
The plan may have been changed.
```

`may + have + been + changed` 共同构成谓语，依次传递推测、完成、被动和主要动作。切成“计划可能有是改变”当然无从理解；应整体译为“该计划可能已经被修改”。分析谓语时，先从最左侧的情态/助动词一路找到主要动词，再判断其余成分。

常见骨架包括：

| 形式 | 例子 | 主要信息 |
| ---- | ---- | -------- |
| 情态 + 动词原形 | `may change` | 可能、能力、义务等 |
| have + done | `has changed` | 到某时点已完成/形成结果 |
| be + doing | `is changing` | 正在进行或暂时状态 |
| be + done | `is changed` | 被动或状态，依语境判断 |
| 情态 + 完成/被动组合 | `may have been changed` | 多层语气与时间 |

## 非谓语的三种形式与常见职责

| 形式 | 常见职责 | 例子 |
| ---- | -------- | ---- |
| `to do` | 目的、将来倾向、名词性内容、后置定语 | `a chance to improve` |
| `doing` | 主动进行、伴随、方式、动名词 | `students learning English` |
| `done` | 被动、完成后的状态 | `data collected last year` |

关键不在翻译时一定要写出“去、正在、被”，而在于判断它和被修饰者的逻辑关系。

```text
The company hired experts to solve the problem.
```

`to solve` 常表目的：“公司聘请专家来解决问题”。

```text
The company hired experts trained in data security.
```

`trained ...` 修饰 `experts`，表示被动/完成关系：“公司聘请了受过数据安全训练的专家”。若误把两个非谓语都翻成另一个主句动作，主干数量就会莫名增加。

## 非谓语的逻辑主语：谁在做这个动作

```text
Walking through the park, Maria saw an old friend.
```

`Walking ...` 的逻辑主语通常是主句主语 `Maria`，即“玛丽亚穿过公园时，看见了一位老朋友”。若写成 `Walking through the park, the trees looked beautiful.`，字面上变成“树在公园里走”，便是悬垂修饰（dangling modifier）。阅读中遇到分词短语，也要优先把它接到最合理的逻辑主语上。

有时逻辑主语明确写出：

```text
With the weather improving, the event can continue.
```

`with + 名词 + doing/done` 构成独立结构，表示“随着天气好转”。它不是另一个完整谓语，却提供了主句成立的背景。

## 系动词不只有 `be`

系动词连接主语和表语，重点不在“做了什么动作”，而在说明主语的身份、状态、变化或外在表现。常见类别如下：

| 类别 | 常见词 | 例子 |
| ---- | ------ | ---- |
| 状态/保持 | `be`, `remain`, `stay`, `keep` | `The room remained quiet.` |
| 变化 | `become`, `get`, `grow`, `turn`, `fall` | `The problem became serious.` |
| 感官印象 | `look`, `sound`, `smell`, `taste`, `feel` | `The idea sounds reasonable.` |
| 似乎/结果 | `seem`, `appear`, `prove` | `The method proved effective.` |

这些词常有实义动词用法，不能只凭词本身判定。`She looked at the map.` 中 `looked at` 是动作，后面是介词宾语；`She looked tired.` 中 `looked` 后接形容词表语，表示“看起来累”。同一拼写，不同结构，职责不同。

## 表语、宾补与常见动词结构

```text
The soup tastes good.                 # good 是主语 soup 的表语
They made the soup taste better.      # taste better 说明宾语 soup 的结果
They found the soup too salty.        # too salty 是宾补
```

宾补常见于 `make/keep/find/consider/call/think/see/hear` 等动词后。它可以是名词、形容词、不定式、分词等：

```text
They elected her president.
We expect the work to finish soon.
I saw him leave the building.
I saw him leaving the building.
```

最后两句都与“看见他离开”有关，但 `leave` 常把动作看作完整事件，`leaving` 更强调过程或当时进行。这类细微差别应在结构已确认后再处理；先看清 `him` 是 `saw` 的宾语、后面是其补足信息，才不会将它们误作并列谓语。

## 小结

- 情态、助动词和主要动词常构成一个谓语动词组，应整体保留语气、时间和语态。
- `to do`、`doing`、`done` 的意义取决于它们在句中做什么，以及与逻辑主语的主动/被动关系。
- 系动词还包括 `seem`、`become`、`remain`、`look`、`prove` 等；看其后接表语还是宾语/介词短语。
- 补语紧扣主语或宾语的身份、状态或结果，不能随意当成可删的状语。
