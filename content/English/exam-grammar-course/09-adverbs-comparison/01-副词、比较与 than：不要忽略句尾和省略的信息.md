副词和比较结构常因“词很小、位置很灵活”而被忽略。可它们往往决定作者说得有多肯定、动作以何种方式发生、两个对象究竟比较什么。句尾的 `carefully` 不是无关紧要的尾巴，`than` 也不只是一个可以随手译成“比”的标签；二者都需要先看作用范围。

## 副词修饰什么：不要只看它站在哪里

副词可以修饰动词、形容词、其他副词、整个分句，少数还可限定名词短语。常见功能比“副词通常修饰动词”更宽：

| 功能 | 例句 | 含义 |
| ---- | ---- | ---- |
| 修饰动词 | `The team worked carefully.` | 工作得仔细 |
| 修饰形容词 | `a very difficult task` | 非常困难的任务 |
| 修饰副词 | `worked very carefully` | 非常仔细地工作 |
| 修饰整句 | `Fortunately, nobody was hurt.` | 说话者评价：幸运的是 |
| 表示概率/立场 | `The plan will probably fail.` | 很可能失败 |

`carefully` 在句尾依然修饰 `worked`；英语把方式、地点、时间等可扩展信息放在谓语后十分常见。反过来，句首 `probably`、`fortunately` 往往影响整个判断，而不是只修饰紧挨的词。

```text
Only Maria agreed.        # 只有玛丽亚同意
Maria only agreed.        # 常指她只是同意，未必做其他事
Maria agreed only today.  # 她只是今天才同意
```

`only` 这类焦点副词尤其要看位置和语境；它限定哪一部分，意义就落在哪一部分。阅读时可先问：“如果把 only 改成‘仅仅’，它限制的是人、动作，还是时间？”

## 副词的位置：规律是线索，不是铐链

频率副词如 `always`、`often`、`usually` 常位于实义动词前、`be` 后：`She often reads.`、`She is often tired.`。程度副词常在所修饰形容词/副词前：`quite useful`、`extremely slowly`。方式、地点、时间状语则常在句尾：

```text
They discussed the issue carefully in the office yesterday.
```

这句通常按“方式—地点—时间”排列，但真实语篇还会受强调和信息重心影响。理解时不要背成绝对顺序；要识别每一块回答的是“怎样、在哪里、何时”，然后按中文逻辑安排。

还需避免以词尾机械判词性：`fast`、`hard`、`late` 可作副词；`friendly`、`likely` 常作形容词。`hard`（努力地）与 `hardly`（几乎不）更不是简单的词形变化关系：`He works hard.` 与 `He hardly works.` 的意思相距很远，显然不能靠多一个 `-ly` 解决。

## 比较结构：先找比较的两个对象和共同维度

```text
This method is more reliable than the old one.
```

比较的是 `this method` 与 `the old one`，共同维度是 `reliable`。中文为“这种方法比旧方法更可靠”。若没有先找共同维度，`than` 后的名词很容易被错接到最近动词上。

常见形式如下：

| 结构 | 含义 | 例子 |
| ---- | ---- | ---- |
| `比较级 + than` | 更…… | `faster than before` |
| `as + 原级 + as` | 和……一样…… | `as useful as before` |
| `not as/so + 原级 + as` | 不如……那样…… | `not as useful as before` |
| `the + 比较级, the + 比较级` | 越……越…… | `The more you read, the more you notice.` |
| `more/less + 名词 + than` | 比……更多/更少 | `more time than money` |

`than` 在现代英语中既可后接名词/代词，也可引出简化或完整的比较分句。阅读的重点不是争论它必须贴上哪一种孤立词性，而是补全被省略的相同部分。

```text
She works harder than I do.
She is taller than him.       # 非正式、常见
She is taller than he is.     # 更完整、更正式
```

第一句补全为“她工作比我工作更努力”；第二、三句都在比较身高，差别主要是比较后成分的完整程度与语体。遇到 `than I expected`、`than usual`、`than before`，同样先问：比预期/平常/以前的什么更怎样？

## 比较范围与否定范围

```text
No other student worked harder than Li.
```

这不是“没有其他学生比李努力”，却可自然表达为“没有其他学生比李更努力”，即李最努力或并列最努力。再看：

```text
He is no more patient than I am.
```

常见意思是“他和我一样没有耐心”，因为 `no more ... than` 在此否定两者都具备该性质。它不能简单按表面译为“他不比我更有耐心”后就停止分析；语境与固定比较模式决定实际语气。

比较中的省略也会制造陷阱：

```text
The company hired more engineers than designers.
```

它可能表示“雇的工程师多于设计师”，也可能在更完整语境中表示“公司雇工程师的数量多于雇设计师的数量”。中文可明确为“聘用的工程师人数超过设计师人数”。若原句允许两种结构而上下文没有消歧，阅读时应保留警觉。

## 与 `like`、`as` 的连接

`like` 常是介词，表示相似：`She sings like a professional.`；`as` 常表示身份或方式：`She works as a teacher.`；`as ... as` 则是原级比较。它们的详细区别可参见 [like 与 as 的用法](<../../like 可以作介词吗：与 as、动词和连词用法的区别.md>) 与 [as 的系统辨析](../../as 的用法：介词、连词、关系代词与固定结构的系统辨析.md)。这里要记住的是：比较结构的中心是“比较维度与范围”，不是只给 `as` 或 `than` 找一个中文替身。

## 小结

- 副词可修饰动词、形容词、副词或整个判断；句尾不代表它没有作用对象。
- 副词位置会影响焦点，`only`、`almost`、`even` 等尤其值得逐一确认作用范围。
- 读比较句先找比较双方与共同维度，再补全 `than` 后省略的相同成分。
- 否定与比较结合时要检查范围；表面相近的形式可能表达“一样不……”而非普通的程度比较。
