副词和比较结构常被误认为“句尾附加信息”，实际上它们决定动作的方式、判断的程度、说话者的态度以及两个对象比较的范围。阅读时应先确定副词修饰哪一层结构，再确定比较双方和共同维度；位置有规律，但不是唯一依据。

## 副词的四类修饰对象

| 修饰对象 | 例句 | 作用 |
| -------- | ---- | ---- |
| 动词 | `The rate changed rapidly.` | 说明动作方式/程度 |
| 形容词 | `a highly effective policy` | 说明性质程度 |
| 副词 | `changed very rapidly` | 进一步说明副词程度 |
| 整个分句 | `Fortunately, the error was found.` | 表示说话者评价 |

副词并非一定以 `-ly` 结尾。`fast`、`hard`、`late` 可作副词；`friendly`、`likely`、`lively` 常是形容词。`hard` 与 `hardly` 的意义也不同：`work hard` 是“努力工作”，`hardly work` 是“几乎不工作”。

## 高频副词的位置

频率副词通常位于实义动词前、`be` 后：

```text
Researchers often disagree.
The result is often misunderstood.
The method has already been tested.
```

程度副词多位于所修饰的形容词或副词前：`particularly important`、`closely related`、`far more expensive`。方式、地点、时间副词或状语短语常位于句末：

```text
The researchers examined the data carefully in the laboratory yesterday.
```

这里 `carefully` 修饰 `examined`，`in the laboratory` 表地点，`yesterday` 表时间。句末不意味着它不修饰任何对象；它常是英语放置较长补充信息的位置。

## 影响范围的副词

`only`、`almost`、`even`、`also`、`especially`、`probably` 等副词会改变整句话的重点。比较：

```text
Only the manager approved the plan.  # 只有经理批准
The manager only approved the plan.  # 通常指只做了“批准”这一动作
The manager approved the plan only yesterday. # 直到昨天才批准
```

`only` 紧靠的成分通常是其焦点，但自然语篇中也可能有歧义，需要结合上下文。`not` 的作用范围同样重要：`not necessarily` 是“未必”，`not entirely` 是“不完全”，并不等于完全否定。

## 比较级与原级比较

比较结构需要三个要素：比较对象 A、比较对象 B、共同维度。例如：

```text
This method is more reliable than the old one.
```

比较对象是 `this method` 和 `the old one`，共同维度是 `reliable`。常见结构如下：

| 结构 | 意义 | 例句 |
| ---- | ---- | ---- |
| `比较级 + than` | 比……更…… | `more reliable than before` |
| `as + 原级 + as` | 和……一样…… | `as reliable as before` |
| `not as/so + 原级 + as` | 不如……那样…… | `not as reliable as before` |
| `less + 原级 + than` | 不如……那么…… | `less expensive than expected` |
| `the + 比较级, the + 比较级` | 越……越…… | `The more evidence we have, the more confident we become.` |

`more` 还可以修饰名词：`more evidence than opinion`；`fewer` 用于可数复数，`less` 常用于不可数名词：`fewer errors`、`less time`。

## `than` 后的省略和形式

`than` 后可接名词、代词、非谓语或比较分句。比较分句中常省略重复部分：

```text
She works harder than I do.
The method is more useful than we expected.
The new system uses less energy than the old one.
```

第一句补全为“她工作得比我工作得更努力”；第二句补全为“比我们预期的更有用”。`than him` 在口语中常见，`than he is` 更完整、更正式；阅读理解的关键不是给 `than` 固定贴一个词性标签，而是补出它连接的比较对象和被省略成分。

## 高级比较和否定范围

```text
No other method is more reliable than this one.
The result is no less important than the process.
He is no more patient than I am.
```

第一句通常表示“没有其他方法比这种方法更可靠”，即它最可靠或并列最可靠。第二句表示“结果和过程同样重要”，而非“结果不重要”。第三句常表示“他和我一样没有耐心”。这类表达不能只看到 `no` 或 `less` 就做局部否定，必须把整个比较结构作为单位理解。

## `as`、`like` 与比较

`as ... as` 是原级比较：`as effective as the old method`。`like` 通常是介词，表示相似：`work like a machine`；`as` 还可以表示身份、角色或方式：`work as a researcher`、`do as the guide says`。`as` 与 `like` 的完整专题可参阅英语目录已有文章，但在比较句中最重要的是确认后面接的是名词性成分、完整分句，还是比较结构。

## 小结

- 副词能修饰动词、形容词、副词和整个分句；位置需结合作用范围判断。
- `only`、`almost`、`not necessarily` 等小词会改变焦点和否定强度。
- 比较句先找比较双方与共同维度，再补全 `than` 后省略的信息。
- `no less ... than`、`no more ... than` 等固定比较结构必须整体理解。
