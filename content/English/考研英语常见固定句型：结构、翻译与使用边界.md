考研英语中的“固定句型”不是要求把英语硬翻成一套中文模板，而是高频结构的识别工具。先抓住主干与逻辑关系，再把结构翻译得自然；若只见到 `not ... until ...` 就机械输出“直到……才”，有时反而会把否定范围翻反。下面按阅读、翻译和写作中最常用的结构归纳。

## 一、强调、倒装与形式结构

| 结构 | 常用译法 | 例句与提示 |
| ---- | -------- | ---------- |
| `It is/was ... that/who ...` | 正是……；……的是…… | `It was the policy that changed the market.`：正是这项政策改变了市场。去掉 `It was` 和 `that` 后主干仍成立。 |
| `It is/was not until ... that ...` | 直到……才…… | `It was not until 1990 that the law took effect.`：直到 1990 年该法律才生效。 |
| `It is said/believed that ...` | 据说/人们认为…… | 注意 `that` 后才是真正内容。 |
| `It is + adj. + for/of sb. to do` | 对某人来说做……是…… | `for` 多评价事情的难易必要；`of` 多评价人的品质：`It was kind of her to help.` |
| `There is no denying that ...` | 不可否认…… | 后接完整陈述内容，不必译得生硬。 |

### 否定副词置前引起的倒装

`never`、`rarely`、`seldom`、`little`、`not until`、`not only` 等否定或限制性成分置于句首时，常出现部分倒装：助动词/系动词/情态动词移到主语前。

```text
Never have we faced such a challenge.
我们从未面临过如此严峻的挑战。

Not until the data were examined did the error become clear.
直到核查数据后，这个错误才变得清楚。
```

翻译的重点是还原否定和时间逻辑，不需要在中文中也“倒装”。

## 二、条件、让步和比较

| 结构 | 常用译法 | 要点 |
| ---- | -------- | ---- |
| `if ...` | 如果…… | 真实条件；注意时态不必逐词对应中文。 |
| `unless ...` | 除非……；如果不…… | `unless` 本身含否定，通常不要再译一个多余的“不”。 |
| `provided/providing (that) ...` | 只要……；前提是…… | 比普通 `if` 更强调条件。 |
| `as/so long as ...` | 只要…… | `as long as` 也可表示“和……一样长”，须按语境判断。 |
| `even if/though ...` | 即使…… | 表示假设性让步。 |
| `no matter + 疑问词` / `疑问词-ever` | 无论…… | `Whatever happens, ...`：无论发生什么…… |
| `more ... than ...` | 与其说……不如说……；比……更…… | 若比较的是性质而非数量，前一种往往更自然。 |
| `no more ... than ...` | ……同……一样不…… | 两边都否定：`A whale is no more a fish than a horse is.` 鲸和马一样，都不是鱼。 |
| `not so much A as B` | 与其说 A，不如说 B | 强调 B 才是更准确的描述。 |

`the + 比较级，the + 比较级` 表示两个变化的联动：

```text
The more carefully you read, the more clearly you will see the argument.
你读得越仔细，就越能清楚看出论证思路。
```

不要把第一个 `the` 当成冠词。它是比较结构的一部分。

## 三、目的、结果、程度与原因

| 结构 | 常用译法 | 示例 |
| ---- | -------- | ---- |
| `so that ...` | 以便……；因此…… | 目的或结果要靠语境判断。 |
| `so ... that ...` | 如此……以至于…… | `so` 后接形容词/副词。 |
| `such ... that ...` | 如此……以至于…… | `such` 后接名词短语。 |
| `too ... to do` | 太……而不能…… | 注意否定语境：`not too ... to` 常可译为“并非太……以至于不能”。 |
| `... enough to do` | 足够……可以…… | `enough` 在形容词/副词后。 |
| `so as to / in order to do` | 为了…… | 后接动词原形，表示目的。 |
| `because/since/as + 从句` | 因为…… | `since/as` 的原因语气常较弱，也可能表示时间或方式。 |

```text
The evidence was so limited that no firm conclusion could be drawn.
证据极其有限，因而无法得出确切结论。

It was such a complex issue that a single measure could not solve it.
问题如此复杂，单一措施无法解决。
```

## 四、非谓语结构：先找逻辑主语

非谓语不是“没有谓语”，而是不能独立充当句子主句谓语的动词形式。翻译时先问：这个动作是谁做的、和主句动作是什么关系。

| 结构 | 常用译法 | 示例 |
| ---- | -------- | ---- |
| `doing ...` | 正在……；通过……；由于…… | `Using the method, researchers reduced the cost.`：研究者通过采用该方法降低了成本。 |
| `done ...` | 被……；在……之后/由于…… | `Compared with 2020, sales increased.`：与 2020 年相比，销量上升。 |
| `to do ...` | 为了……；将要…… | `To understand the claim, ...`：为了理解这一观点…… |
| `having done ...` | 在已经……之后 | 表示动作先于主句，正式文体常见。 |
| `with + 名词 + 非谓语/介词短语` | 随着……；在……情况下 | `With prices rising, ...`：随着价格上涨…… |

特别留意悬垂分词：`Walking down the street, the trees looked beautiful.` 表面上成了“树在走路”。分词短语的逻辑主语应能与主句主语对应；考试翻译时也应据此找到真正施事者。

## 五、名词从句与主语从句

| 结构 | 常用译法 | 识别重点 |
| ---- | -------- | -------- |
| `that + 陈述句` | ……这一事实/…… | `that` 在从句中通常不作成分。 |
| `whether/if + 陈述语序` | 是否…… | 介词后、`to do` 前、句首主语从句通常用 `whether`，不用 `if`。 |
| `what + 从句` | ……的事/东西 | `what` 在从句中作成分，等于 `the thing(s) that`。 |
| `why/how/when/where + 从句` | 为什么/如何/何时/何地…… | 仍用陈述语序。 |
| `What matters is that ...` | 重要的是…… | `what` 引导的从句整体作主语。 |

```text
What makes the issue difficult is that the evidence is incomplete.
使这一问题棘手的是，证据并不完整。
```

这里不要把 `what` 误当成疑问句的“什么”。它引导的是一个整体作主语的名词性从句。

## 六、定语从句：先确定它修饰谁

阅读中遇到 `who/which/that/whose/where/when`，先找先行词，再判断从句在补充什么信息。

```text
The report, which was published last week, has drawn attention.
这份上周发表的报告已引起关注。

The report that the committee published last week has drawn attention.
委员会上周发表的那份报告已引起关注。
```

前句有逗号，是非限制性定语从句，补充说明；后句没有逗号，限定“哪一份报告”。翻译时前者可拆为一句补充，后者通常译作前置定语。`the reason why ...`、`the way (that/in which) ...`、`the time when ...` 也都是高频搭配。

## 七、虚拟、建议与“宁愿”

| 结构 | 常用译法 | 示例 |
| ---- | -------- | ---- |
| `If I were ...` | 如果我是…… | 与现在事实相反时常用 `were`。 |
| `If ... had done, ... would have done` | 如果当时……，本会…… | 与过去事实相反。 |
| `suggest/demand/insist that + (should) do` | 建议/要求……做…… | 此处 `insist` 表“坚持要求”；若表“坚持认为”，从句可用陈述语气。 |
| `would rather do A than do B` | 宁愿做 A 也不做 B | 后接动词原形。 |
| `prefer A to B` | 比起 B 更喜欢 A | `to` 是介词，A/B 形式应平行。 |

## 八、翻译时的实用顺序

面对长句，可按这个顺序处理：

1. 圈出谓语，确定主句主干。
2. 划分从句、非谓语和介词短语，找每一块修饰谁。
3. 标出转折、因果、条件、让步、比较等逻辑词。
4. 先译主干，再按中文习惯重排修饰语；必要时拆句。
5. 最后核对否定、比较级、代词指代和时态关系。

固定句型的价值在于让结构更快显形，而不是让译文变成模板展览。中文最终应读得通顺、逻辑不走样，这才算完成任务。
