HTML 和 CSS 是前端页面的地基。很多人学前端时一上来就碰 Vue、React、uni-app、组件库，然后遇到页面错位、文字溢出、滚动失效、图片变形，就完全不知道从哪里查。原因很简单：框架没有取消 HTML 和 CSS，它只是把页面组织方式变得更工程化。

这组文章面向零基础读者。目标不是让你背完所有标签和属性，而是让你能看懂页面结构、写出基础布局、处理常见样式问题，并为后面学习 Vue 组件打基础。

## 一、HTML 和 CSS 分别做什么

一句话：

- **HTML 负责内容结构**。
- **CSS 负责视觉表现**。

例如一张文章卡片：

```html
<article class="post-card">
  <h2>学习 HTML 与 CSS</h2>
  <p>先理解结构，再处理样式。</p>
  <button>阅读全文</button>
</article>
```

这段 HTML 告诉浏览器：这里有一篇文章卡片，里面有标题、摘要和按钮。

CSS 决定它长什么样：

```css
.post-card {
  padding: 16px;
  border: 1px solid #ddd;
  border-radius: 8px;
}

.post-card h2 {
  margin: 0 0 8px;
  font-size: 20px;
}
```

HTML 是骨架，CSS 是衣着、布局和视觉秩序。骨架乱，穿什么都不太体面。

## 二、学习顺序

推荐顺序如下：

```text
网页基本结构
 -> 常见 HTML 标签
 -> 语义化
 -> 表单和图片
 -> CSS 选择器
 -> 盒模型
 -> 文本和颜色
 -> Flex 布局
 -> Grid 布局
 -> 定位和层级
 -> 响应式
 -> 工程化样式组织
```

不要一开始就追求炫酷效果。先能稳定写出普通页面，才有资格谈复杂动画和高级布局。

## 三、前端页面如何被浏览器理解

浏览器拿到 HTML 后，会把它解析成 DOM 树。

```html
<main>
  <section>
    <h2>文章列表</h2>
    <article>
      <h3>标题</h3>
      <p>摘要</p>
    </article>
  </section>
</main>
```

可以理解成：

```text
main
 -> section
   -> h2
   -> article
     -> h3
     -> p
```

CSS 会根据选择器找到这些节点，然后应用样式。

```css
article {
  padding: 16px;
}

article h3 {
  color: #222;
}
```

所以写页面时，你要同时思考两件事：

- 结构是否清楚。
- 样式是否准确命中目标。

## 四、零基础最容易混淆的概念

### 1. 标签和元素

标签是代码里的写法：

```html
<p>这是一段文字</p>
```

浏览器解析后形成页面中的元素。日常交流中常常混用，不必过度纠结，但要知道 HTML 代码会变成浏览器里的 DOM 元素。

### 2. class 和 id

`class` 用来给一类元素命名：

```html
<button class="primary-button">提交</button>
```

`id` 用来标识唯一元素：

```html
<section id="profile"></section>
```

写样式时更推荐使用 class。`id` 优先级高，复用性差，初学阶段少用。

### 3. 块级和行内

块级元素默认独占一行，例如 `div`、`p`、`section`。

行内元素默认跟文字排在一行，例如 `span`、`a`。

后面学习 `display` 时，你会发现这个行为可以改变。

## 五、学到什么程度算入门

小白入门不是“知道 HTML 和 CSS 是什么”，而是能完成这些任务：

- 写出一个完整 HTML 页面。
- 正确使用标题、段落、链接、图片、列表和表单。
- 能解释 class 选择器、后代选择器和伪类。
- 能画出盒模型。
- 能用 Flex 实现水平和垂直排列。
- 能写一个简单响应式卡片列表。
- 能处理文字溢出、图片变形、滚动失效等常见问题。

如果这些都能做到，再去学 Vue 模板和组件，会轻松很多。

## 六、建议练习页面

建议从三个页面练起：

```text
个人资料卡片
 -> 文章列表页
 -> 登录表单页
```

它们覆盖：

- 文本结构。
- 图片显示。
- 按钮。
- 表单。
- 列表布局。
- 卡片样式。
- 移动端适配。

页面越普通，越能训练基本功。不要一开始就做复杂视觉稿，那只会让你把时间花在猜样式上，而不是理解规则。

## 七、学习心态

HTML 和 CSS 看起来简单，是因为语法不复杂；它们真正困难的地方在于规则很多、相互影响明显、浏览器默认样式也会参与结果。

遇到样式问题时，不要急着乱改。按顺序检查：

```text
元素是否存在
 -> class 是否写对
 -> 选择器是否命中
 -> 样式是否被覆盖
 -> 盒模型尺寸是否正确
 -> 父元素布局是否影响子元素
```

能按这个顺序排查，就已经比只会反复改 `margin` 的人强了不少。虽然这话略显直接，但很遗憾，它是真的。
