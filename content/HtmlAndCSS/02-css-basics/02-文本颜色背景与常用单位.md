页面首先要可读，其次才是好看。文字太小、颜色太淡、行高太挤、背景太乱，都会让页面难以使用。CSS 的视觉基础，就是文本、颜色、背景和单位。

## 一、字体大小

设置字体大小：

```css
.title {
  font-size: 24px;
}

.summary {
  font-size: 14px;
}
```

常见建议：

- 正文不要太小，移动端通常至少 14px。
- 标题和正文要有层级差异。
- 不要在一个页面里使用太多字号。

字号不是越大越醒目。所有东西都醒目，等于没有重点。

## 二、字体粗细

```css
.title {
  font-weight: 600;
}

.meta {
  font-weight: 400;
}
```

常见值：

| 值 | 含义 |
| -- | ---- |
| `400` | 正常 |
| `500` | 中等 |
| `600` | 半粗 |
| `700` | 粗体 |

不同字体支持的粗细不同。写了 `600` 不代表一定能精准显示为 600。

## 三、行高

行高影响阅读舒适度：

```css
.content {
  line-height: 1.8;
}
```

正文建议使用 `1.6` 到 `1.9`。行高太小会挤，太大会散。

## 四、文本对齐和溢出

居中：

```css
.title {
  text-align: center;
}
```

单行省略：

```css
.title {
  overflow: hidden;
  white-space: nowrap;
  text-overflow: ellipsis;
}
```

多行省略：

```css
.summary {
  display: -webkit-box;
  overflow: hidden;
  -webkit-line-clamp: 2;
  -webkit-box-orient: vertical;
}
```

省略号不是解决所有问题的神技。重要内容不应该随便截断。

## 五、颜色写法

常见颜色写法：

```css
.text {
  color: #222;
}

.muted {
  color: rgb(100, 116, 139);
}

.mask {
  background: rgba(0, 0, 0, 0.4);
}
```

推荐工程中使用十六进制、RGB/RGBA 或 CSS 变量。不要一个页面到处随手取颜色，最后会变成色彩样本展览。

## 六、背景

纯色背景：

```css
.page {
  background-color: #f7f8fa;
}
```

背景图：

```css
.hero {
  background-image: url('/images/cover.jpg');
  background-size: cover;
  background-position: center;
}
```

常用属性：

| 属性 | 作用 |
| ---- | ---- |
| `background-color` | 背景颜色 |
| `background-image` | 背景图片 |
| `background-size` | 背景尺寸 |
| `background-position` | 背景位置 |
| `background-repeat` | 是否重复 |

## 七、边框和圆角

```css
.card {
  border: 1px solid #e5e7eb;
  border-radius: 8px;
}
```

圆角要克制。小卡片可以 6px 到 8px，头像可以 50%。过度圆角会让界面显得不稳重。

## 八、阴影

```css
.card {
  box-shadow: 0 8px 24px rgba(15, 23, 42, 0.08);
}
```

阴影用于表达层级，但不要滥用。每个元素都加阴影，页面就会显得浮躁。

## 九、常用单位

| 单位 | 含义 | 常见用途 |
| ---- | ---- | -------- |
| `px` | 像素 | 边框、固定间距、字号 |
| `%` | 相对父元素 | 宽度、高度 |
| `em` | 相对当前字体大小 | 局部缩放 |
| `rem` | 相对根字体大小 | 全局尺寸体系 |
| `vw` | 视口宽度百分比 | 全屏宽度 |
| `vh` | 视口高度百分比 | 首屏高度 |

小白阶段可以先熟练使用 `px`、`%`、`rem`、`vw`、`vh`。

## 十、CSS 变量

CSS 变量适合统一颜色和尺寸。

```css
:root {
  --color-text: #1f2937;
  --color-muted: #64748b;
  --space-md: 16px;
}

.card {
  padding: var(--space-md);
  color: var(--color-text);
}
```

变量能降低重复，让主题调整更容易。

## 十一、练习

给文章卡片添加视觉样式：

- 标题 20px、半粗。
- 摘要 14px、灰色、两行省略。
- 卡片白色背景。
- 8px 圆角。
- 浅色边框。
- 鼠标悬停时边框颜色变深。

练习重点不是炫，而是清楚、可读、稳定。审美可以慢慢培养，混乱倒是很容易一开始就养成。
