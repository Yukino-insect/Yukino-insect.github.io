子网掩码的核心作用是：**把 IP 地址划分成网络部分和主机部分，让设备判断目标 IP 是否和自己在同一个网段。**

如果在同一个网段，设备可以在局域网内直接通信；如果不在同一个网段，就要把数据交给默认网关转发。

## 一、先理解网卡和 IP

网卡是设备接入网络的接口。常见形式包括：

1. 有线网卡。
2. 无线网卡。
3. 服务器多口网卡。
4. 虚拟机虚拟网卡。
5. Docker、VPN、TUN 创建的虚拟网络接口。

IP 地址通常配置在网卡上。

一台机器可以有多个网卡，一个网卡也可能配置多个 IP。操作系统发送数据时，会根据目标地址、路由表和网卡配置，决定从哪个接口发出去。

## 二、IP 地址不是孤立存在的

一台设备要正常上网，通常需要这些配置：

```text
IP 地址
子网掩码
默认网关
DNS 服务器
```

它们分别解决不同问题：

| 配置 | 作用 |
| --- | --- |
| IP 地址 | 标识当前设备在网络中的逻辑地址 |
| 子网掩码 | 判断哪些 IP 属于本地网段 |
| 默认网关 | 访问外部网段时交给谁转发 |
| DNS | 把域名解析成 IP 地址 |

所以子网掩码不是可有可无的附属品。没有它，设备就不知道哪些目标可以直接访问，哪些目标必须交给网关。

## 三、子网掩码是什么

子网掩码是一串 32 位二进制数，用来标识 IP 地址中哪些位属于网络号，哪些位属于主机号。

例如：

```text
IP 地址：    192.168.1.10
子网掩码：  255.255.255.0
CIDR 写法：192.168.1.10/24
```

`255.255.255.0` 转成二进制是：

```text
11111111.11111111.11111111.00000000
```

前 24 位是 1，表示前 24 位是网络部分；后 8 位是 0，表示后 8 位是主机部分。

因此：

```text
192.168.1.10/24
```

表示这台主机属于：

```text
192.168.1.0/24
```

这个网段。

## 四、如何判断两个 IP 是否同网段

判断方法是：**IP 地址和子网掩码做按位与运算，得到网络地址。**

例如本机：

```text
IP：      192.168.1.10
掩码：    255.255.255.0
网络地址：192.168.1.0
```

目标一：

```text
目标 IP： 192.168.1.20
掩码：    255.255.255.0
网络地址：192.168.1.0
```

网络地址相同，所以在同一个网段。

目标二：

```text
目标 IP： 192.168.2.20
掩码：    255.255.255.0
网络地址：192.168.2.0
```

网络地址不同，所以不在同一个网段。

## 五、同网段和不同网段怎么通信

### 1. 同网段通信

如果目标 IP 和本机在同一个网段，主机会通过 ARP 查询目标 IP 对应的 MAC 地址，然后直接在二层网络中发送数据帧。

流程简化如下：

```text
判断目标同网段
  -> ARP 查询目标 MAC
  -> 直接发给目标主机
```

### 2. 不同网段通信

如果目标 IP 不在同一个网段，主机会把数据交给默认网关。

流程简化如下：

```text
判断目标不同网段
  -> ARP 查询默认网关 MAC
  -> 把数据帧发给网关
  -> 网关继续路由转发
```

注意：此时二层目的 MAC 是网关的 MAC，但三层目的 IP 仍然是最终目标 IP。

## 六、常见 CIDR 对照

| CIDR | 子网掩码 | 可用主机数 |
| --- | --- | --- |
| `/24` | `255.255.255.0` | 254 |
| `/25` | `255.255.255.128` | 126 |
| `/26` | `255.255.255.192` | 62 |
| `/16` | `255.255.0.0` | 65534 |
| `/8` | `255.0.0.0` | 16777214 |

可用主机数通常要减去网络地址和广播地址，所以 `/24` 不是 256 台，而是 254 台。

例如：

```text
192.168.1.0/24
```

含义是：

```text
网络地址：192.168.1.0
可用主机：192.168.1.1 ~ 192.168.1.254
广播地址：192.168.1.255
```

## 七、子网掩码配置错会怎样

### 1. 掩码过大

例如本来应该是：

```text
192.168.1.10/24
```

却配置成：

```text
192.168.1.10/32
```

主机会认为几乎没有本地网段，很多本该直接访问的地址都会被交给网关。

### 2. 掩码过小

例如本来应该是：

```text
192.168.1.10/24
```

却配置成：

```text
192.168.1.10/16
```

主机会误以为 `192.168.x.x` 都在本地网段，访问某些地址时不会交给网关，导致通信失败。

## 八、面试时怎么回答

可以这样说：

> 子网掩码用于区分 IP 地址中的网络位和主机位。主机会用自己的 IP 和子网掩码计算出网络地址，再用目标 IP 和同一个掩码计算目标网络地址。如果两者相同，说明目标在本地网段，可以通过 ARP 获取 MAC 后直接通信；如果不同，就把数据交给默认网关转发。

## 九、一句话总结

子网掩码决定了设备如何判断“目标在不在本地网段”。它直接影响 ARP、默认网关选择和路由转发，是 IP 通信中非常基础但不能含糊的配置。
