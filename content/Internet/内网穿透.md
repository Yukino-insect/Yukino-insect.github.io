内网穿透是让外部网络能够访问内网服务的一种技术。它通常用于本地开发调试、远程访问家中设备、临时暴露测试服务等场景。

## 一、为什么需要内网穿透

多数个人电脑、家庭网络和公司办公网络都在 NAT 后面。内网机器只有私有 IP，例如 `192.168.x.x`、`10.x.x.x`，公网用户无法直接访问这些地址。

如果内网服务需要被外部访问，就需要一个公网入口。内网穿透的做法是：内网客户端主动连接到一台有公网 IP 的中转服务器，再由中转服务器把外部请求转发回内网服务。

## 二、基本工作方式

典型链路如下：

```text
外部用户 -> 公网中转服务器 -> 内网穿透客户端 -> 内网服务
```

内网机器不能被公网主动连接，但它可以主动连接公网服务器。内网穿透正是利用这个方向上的可达性，建立一条长期连接或隧道。公网请求到达中转服务器后，再通过这条隧道转发到内网。

## 三、常见工具

常见内网穿透工具包括：

1. `frp`：自建场景常用，功能完整，适合长期使用。
2. `ngrok`：使用简单，适合临时调试。
3. `ssh -R`：通过 SSH 远程端口转发实现简单穿透。
4. 云厂商提供的隧道服务：适合和云资源集成。

如果只是临时给前端或第三方回调调试本地接口，使用托管型工具更省事。如果是长期暴露内部服务，建议自建并配置鉴权、TLS、访问控制和审计。

## 四、安全注意点

内网穿透会把原本只在内网可见的服务暴露出去，因此安全边界会发生变化。至少要注意：

1. 不要暴露数据库、缓存、管理后台等高危端口。
2. 公网入口必须配置认证和访问控制。
3. 对外服务应使用 HTTPS。
4. 测试完成后及时关闭隧道。
5. 服务日志中不要输出敏感凭证。

内网穿透解决的是网络可达性问题，不解决服务本身的安全问题。服务一旦暴露到公网，就应该按公网服务的标准进行防护。
