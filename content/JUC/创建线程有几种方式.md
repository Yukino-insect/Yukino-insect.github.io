Java 中常见的创建线程方式有四类，但从本质上看，最终真正创建操作系统线程的仍然是 `Thread`。

## 一、继承 Thread

可以继承 `Thread` 并重写 `run` 方法：

```java
class MyThread extends Thread {
    @Override
    public void run() {
        System.out.println("running");
    }
}
```

使用时调用 `start`，不要直接调用 `run`。`start` 会创建新线程，`run` 只是普通方法调用。

## 二、实现 Runnable

更常见的方式是实现 `Runnable`：

```java
Runnable task = () -> System.out.println("running");
new Thread(task).start();
```

这种方式把任务和线程对象分离，更适合组合和复用。

## 三、实现 Callable

`Callable` 可以返回结果，也可以抛出受检异常，通常配合 `FutureTask` 或线程池使用：

```java
Callable<Integer> task = () -> 1;
FutureTask<Integer> futureTask = new FutureTask<>(task);
new Thread(futureTask).start();
Integer result = futureTask.get();
```

## 四、使用线程池

生产环境更推荐使用线程池，而不是频繁手动创建线程：

```java
ExecutorService executor = Executors.newFixedThreadPool(4);
executor.submit(() -> System.out.println("running"));
executor.shutdown();
```

线程池可以复用线程，限制并发数量，并统一处理任务队列、拒绝策略和关闭流程。

## 五、总结

从写法上看，创建线程可以通过 `Thread`、`Runnable`、`Callable` 和线程池完成。从执行机制看，`Runnable` 和 `Callable` 只是任务描述，真正承载执行的仍然是线程。实际项目中应优先使用线程池，并避免无边界创建线程。
