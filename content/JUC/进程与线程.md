进程和线程是理解 Java 并发前必须先分清的两个概念。简单说：**进程负责资源隔离，线程负责执行调度**。

## 一、核心概念

进程是操作系统进行资源分配的基本单位。每个进程都有相对独立的地址空间、文件句柄、环境变量等资源。

线程是 CPU 调度的基本单位。同一个进程中的多个线程共享进程资源，例如堆内存、方法区、打开的文件句柄，但每个线程又有自己的程序计数器、虚拟机栈和本地方法栈。

可以这样理解：

```text
进程
 ├─ 堆内存、方法区、文件句柄等共享资源
 ├─ 线程 A：程序计数器、栈、本地方法栈
 ├─ 线程 B：程序计数器、栈、本地方法栈
 └─ 线程 C：程序计数器、栈、本地方法栈
```

## 二、进程和线程的区别

| 对比项 | 进程 | 线程 |
| --- | --- | --- |
| 资源拥有 | 拥有独立资源空间 | 共享所属进程资源 |
| 调度成本 | 创建和切换成本较高 | 创建和切换成本较低 |
| 隔离性 | 隔离性强，一个进程崩溃通常不影响其他进程 | 隔离性弱，一个线程异常可能影响整个进程 |
| 通信方式 | 需要 IPC、Socket、管道等机制 | 可直接共享内存，但需要同步控制 |
| Java 对应 | `Process` | `Thread` |

多进程更稳定，因为隔离性更强；多线程更轻量，因为线程之间共享资源，通信成本更低。代价也很明显：共享资源如果没有正确同步，就会出现竞态条件、可见性问题、死锁等并发问题。

## 三、Java 中创建进程

Java 中可以通过 `ProcessBuilder` 创建外部进程：

```java
ProcessBuilder builder = new ProcessBuilder("java", "-version");
builder.redirectErrorStream(true);

Process process = builder.start();
try (BufferedReader reader = new BufferedReader(
        new InputStreamReader(process.getInputStream()))) {
    String line;
    while ((line = reader.readLine()) != null) {
        System.out.println(line);
    }
}

int exitCode = process.waitFor();
System.out.println("exitCode=" + exitCode);
```

也可以使用 `Runtime.getRuntime().exec()`，但实际项目中更推荐 `ProcessBuilder`。它对命令参数、工作目录、环境变量和输出重定向的控制更清楚，不容易因为空格、引号和平台差异出问题。

## 四、Java 中创建线程

线程通常通过 `Thread` 或线程池创建：

```java
Thread thread = new Thread(() -> {
    System.out.println(Thread.currentThread().getName());
});
thread.start();
```

生产环境一般不建议无限制地手动创建线程，而是使用线程池统一管理线程数量、任务队列、拒绝策略和关闭流程。

## 五、总结

- 进程是资源分配单位，线程是 CPU 调度单位。
- 同一进程内的线程共享堆内存等资源，因此通信方便，但也需要同步。
- Java 可以通过 `ProcessBuilder` 启动外部进程，通过 `Thread` 或线程池执行并发任务。
- JUC 主要解决的是多线程共享资源时的同步、协作和任务编排问题。
