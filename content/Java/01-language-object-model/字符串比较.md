Java 中比较字符串时，最常见的问题是把 `==`、`equals` 和 `compareTo` 混在一起。

先给结论：

- 判断内容是否相等，用 `equals`。
- 判断内容是否相等且可能有 `null`，用 `Objects.equals`。
- 判断字典序大小，用 `compareTo`。
- 按特定语言环境排序，用 `Collator`。
- 不要用 `==` 判断字符串内容。

## 一、== 比较的是什么

`==` 比较的是两个引用是否指向同一个对象。

```java
String a = "abc";
String b = "abc";

System.out.println(a == b);
```

这可能输出：

```text
true
```

原因是字符串字面量进入字符串常量池，`a` 和 `b` 可能指向同一个对象。

但：

```java
String a = "abc";
String b = new String("abc");

System.out.println(a == b);
```

输出：

```text
false
```

虽然内容一样，但不是同一个对象。

所以 `==` 不能用来判断字符串内容。

## 二、equals 比较内容

判断字符串内容是否相等：

```java
"abc".equals("abc"); // true
```

变量比较：

```java
String name = "Alice";

if ("Alice".equals(name)) {
    System.out.println("matched");
}
```

把常量写在左边，可以避免空指针。

```java
String name = null;

"Alice".equals(name); // false
```

如果写成：

```java
name.equals("Alice");
```

会抛出 `NullPointerException`。

更通用的写法：

```java
Objects.equals(a, b)
```

它可以安全处理 `null`。

## 三、equalsIgnoreCase

忽略大小写比较：

```java
"abc".equalsIgnoreCase("ABC"); // true
```

适合：

- 简单英文命令。
- HTTP header 名称。
- 状态码文本。

但涉及自然语言时，大小写规则可能和语言环境有关，不要随便拿它处理所有国际化排序问题。

## 四、compareTo 比较字典序

`compareTo` 用来比较字符串顺序。

```java
"abc".compareTo("abd"); // 小于 0
"abc".compareTo("abc"); // 等于 0
"abd".compareTo("abc"); // 大于 0
```

返回值规则：

```text
小于 0：当前字符串更小
等于 0：两个字符串相等
大于 0：当前字符串更大
```

不要依赖具体返回值是多少，只判断正负和零。

```java
if (a.compareTo(b) < 0) {
    ...
}
```

## 五、字典序规则

字符串比较会从左到右逐个字符比较。

```java
"abc".compareTo("abd") < 0
```

比较过程：

```text
a 和 a 相同
b 和 b 相同
c 小于 d
所以 abc 小于 abd
```

如果前缀相同，较短字符串更小。

```java
"ab".compareTo("abc") < 0
```

大小写会影响结果：

```java
"A".compareTo("a") < 0
```

因为 `compareTo` 基于 Unicode 编码单元比较。

## 六、compareToIgnoreCase

忽略大小写的顺序比较：

```java
"abc".compareToIgnoreCase("ABC") == 0
```

适合简单场景。

但如果是面向用户的自然语言排序，例如中文、德语、法语，应该考虑 `Collator`。

## 七、Collator

`Collator` 用于按特定语言环境比较字符串。

```java
Collator collator = Collator.getInstance(Locale.CHINA);

int result = collator.compare("张三", "李四");
```

排序列表：

```java
List<String> names = new ArrayList<>(List.of("张三", "李四", "王五"));
Collator collator = Collator.getInstance(Locale.CHINA);

names.sort(collator);
```

`compareTo` 适合程序内部稳定排序，`Collator` 更适合展示给用户看的自然语言排序。

## 八、空字符串和空白字符串

空字符串：

```java
"".isEmpty(); // true
```

空白字符串：

```java
"   ".isBlank(); // true
```

`isBlank` 会判断是否全是空白字符，JDK 11 开始可用。

```java
String value = "   ";

if (value == null || value.isBlank()) {
    System.out.println("blank");
}
```

如果要兼容更早版本，可以：

```java
value == null || value.trim().isEmpty()
```

## 九、排序示例

按姓名字典序：

```java
users.sort(Comparator.comparing(User::getName));
```

处理 `null`：

```java
users.sort(Comparator.comparing(
    User::getName,
    Comparator.nullsLast(String::compareTo)
));
```

按中文环境：

```java
Collator collator = Collator.getInstance(Locale.CHINA);

users.sort(Comparator.comparing(
    User::getName,
    Comparator.nullsLast(collator)
));
```

## 十、总结

字符串比较可以这样记：

```text
==                 -> 比较引用，不比较内容
equals             -> 比较内容
Objects.equals     -> null 安全地比较内容
equalsIgnoreCase   -> 忽略大小写比较内容
compareTo          -> Unicode 字典序
compareToIgnoreCase -> 忽略大小写的顺序比较
Collator           -> 语言环境相关排序
```

日常开发里，字符串内容相等优先写：

```java
Objects.equals(a, b)
```

或者常量在左：

```java
"OK".equals(status)
```
