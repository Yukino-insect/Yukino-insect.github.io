Java 中判断两个字符串内容是否相等，通常使用 `String#equals`。如果要比较两个字符串的大小，则使用 `String#compareTo`。

## 一、equals 和 compareTo 的区别

`equals` 只关心两个字符串内容是否完全相同：

```java
"abc".equals("abc"); // true
```

`compareTo` 关心字典序大小：

```java
"abc".compareTo("abd"); // 小于 0
```

返回值规则是：

1. 等于 `0`：两个字符串相等。
2. 小于 `0`：当前字符串更小。
3. 大于 `0`：当前字符串更大。

## 二、字典序规则

字符串大小比较会从左到右逐个字符比较。

规则如下：

1. 从下标 `0` 开始比较。
2. 如果当前字符相同，继续比较下一个字符。
3. 遇到第一个不同字符时，由该字符的编码值决定大小。
4. 如果较短字符串已经比较完且前面都相同，则较短字符串更小。

例如：

```java
"abc".compareTo("abd") < 0
"abc".compareTo("ab") > 0
```

## 三、大小写影响

Java 的 `String#compareTo` 基于 Unicode 值比较，因此大小写会影响结果。

例如：

```java
"A".compareTo("a") < 0
```

如果希望忽略大小写，可以使用：

```java
"A".compareToIgnoreCase("a")
```

## 四、注意语言环境

`compareTo` 适合一般编码顺序比较。如果要按照特定语言环境排序，例如中文拼音、德语变音字符等，应使用 `Collator`。

```java
Collator collator = Collator.getInstance(Locale.CHINA);
collator.compare("张三", "李四");
```

## 五、总结

内容相等用 `equals`，字典序比较用 `compareTo`，面向自然语言排序则考虑 `Collator`。
