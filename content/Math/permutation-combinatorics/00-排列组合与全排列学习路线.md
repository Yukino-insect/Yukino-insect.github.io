“全排列”常被当作一道回溯题：写一个 `dfs`，不断交换或标记元素，最后输出答案。这样的理解太窄了。全排列首先是一个**有顺序的计数对象**；它连接着乘法原理、组合、重复元素的除重、字典序、逆序数、排序算法，以及把一个排列映射为整数的康托展开。

本系列的目标不是让你背下 $n!$，而是建立一条可以反复使用的判断链：**题目是否在意位置顺序？是否允许重复选择？输入值是否重复？需要枚举全部结果、只计数，还是定位第 $k$ 个结果？** 这几个问题想清楚，工具自然会收敛，不必把每件事都交给回溯——那未免有些粗暴。

## 一、这套知识解决什么问题

设有 $n$ 个互不相同的元素。把它们全部排进 $n$ 个有区别的位置，得到的每一种顺序叫作一个**全排列**。例如 $\{A,B,C\}$ 的全排列包括 `ABC`、`ACB`、`BAC` 等，共有 $3!=6$ 个。

排列组合问题表面上经常换成座位、密码、抽样、比赛名次或数组重排；内核却通常落在下表中的某一类：

| 需求 | 关键对象 | 典型工具 |
| ---- | -------- | -------- |
| 求方案数，顺序重要 | 排列 | $A_n^m$、乘法原理 |
| 求方案数，顺序不重要 | 组合 | $C_n^m$、补集、分类 |
| 列出所有不同顺序 | 全排列 | 回溯、交换、`next_permutation` |
| 输入含相同值 | 多重集合排列 | 除以重复阶乘、去重回溯 |
| 求第 $k$ 个或某排列的序号 | 字典序排列 | 阶乘进制、康托展开 |
| 判断交换次数奇偶性 | 排列的结构性质 | 逆序数、奇偶排列 |

## 三、统一约定

全文中：

- $n$ 表示可用的不同元素数；$m$ 表示从中选出的元素数，且 $0\le m\le n$。
- $n!$ 读作“$n$ 的阶乘”，定义为 $n!=n(n-1)\cdots2\cdot1$，并约定 $0!=1$。
- $A_n^m$ 表示从 $n$ 个不同元素中取 $m$ 个排成一列的排列数；$C_n^m$ 表示不考虑顺序的选法数。
- 若排列写成 $(p_1,p_2,\ldots,p_n)$，默认元素彼此不同，除非特别说明“重复元素”。
- “第 $k$ 个”必须额外说明从 $0$ 还是从 $1$ 开始计数。本文康托展开使用 **0-based** 序号，这样第一项的编号是 $0$。

## 四、先记住的两条边界

第一，$n!$ 增长极快。$10!=3\,628\,800$ 尚可勉强枚举，$15!\approx1.31\times10^{12}$ 则不可能逐个输出。若题目只问方案数、排名或第 $k$ 个结果，枚举全部排列从一开始就是错误方向。

第二，“元素不同”与“位置不同”不能混为一谈。数组 `[1,1,2]` 有 $3!=6$ 种位置排列的过程，却只对应 `112`、`121`、`211` 三种**不同值序列**。这正是后面需要除重和去重搜索的原因。

读完本系列后，你应能把“全排列”从一个模板题还原成一个结构化对象：既知道如何生成，也知道何时应绕开生成；既会计算数量，也能解释每一步为什么不会漏、不会重。
