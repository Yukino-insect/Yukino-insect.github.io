字典序把排列排成一个稳定的线性顺序，就像词典比较单词：从左到右看第一个不同位置，那个位置较小的排列排在前面。对于数字排列，`123 < 132 < 213`。有了它，我们才能严谨地谈“下一个排列”“第 $k$ 个排列”，而不是含糊地说“下一个看起来更大的顺序”。

## 一、为什么下一个排列只需改动一个后缀

设数组为 $a_0,a_1,\ldots,a_{n-1}$。要找刚好比当前排列大的字典序排列，应尽量让左侧保持不变，只在尽可能靠右的位置增加一点点。因此先从右往左寻找最长的非递增后缀。

若找到最大下标 $i$ 使：

$$
a_i<a_{i+1},
$$

则 $i$ 是可以“增大”的最右位置。后缀 $a_{i+1}\ldots a_{n-1}$ 已按非递增排列；从后缀中选择**刚好大于** $a_i$ 的最小值，把它换到位置 $i$，再把后缀升序排列，就得到紧邻的下一个排列。

## 二、三步算法

1. 从右向左找第一个满足 `a[i] < a[i + 1]` 的 `i`。
2. 若存在 `i`，从右向左找第一个 `a[j] > a[i]`，交换 `a[i]` 与 `a[j]`。
3. 反转后缀 `[i + 1, n)`；若不存在 `i`，反转整个数组，回到最小排列。

后缀原本非递增，反转后正好升序，所以第 3 步是 $O(n)$，不必额外排序。

```cpp
#include <algorithm>
#include <vector>

bool nextPermutation(std::vector<int>& a) {
    int i = static_cast<int>(a.size()) - 2;
    while (i >= 0 && a[i] >= a[i + 1]) --i;

    if (i < 0) {
        std::reverse(a.begin(), a.end());
        return false;  // 原数组已是最大排列
    }

    int j = static_cast<int>(a.size()) - 1;
    while (a[j] <= a[i]) --j;
    std::swap(a[i], a[j]);
    std::reverse(a.begin() + i + 1, a.end());
    return true;
}
```

例：`1 3 5 4 2`。从右看，`5 4 2` 是非递增后缀，枢轴是 `3`；后缀中刚大于 `3` 的最小元素是 `4`。交换得 `1 4 5 3 2`，反转后缀得到 `1 4 2 3 5`，这就是下一个排列。

`std::next_permutation` 已实现这套逻辑。若先将容器排序，再在 `do...while` 循环中调用它，便能按字典序枚举；它也能正确跳过重复值产生的相同值序列。

## 三、阶乘进制：直接取第 k 个排列

对 $n$ 个不同元素，若第一个位置固定为某个元素，剩余 $n-1$ 个元素有 $(n-1)!$ 个排列。因此字典序列表可分成大小相同的块：

$$
(n-1)!, (n-1)!, \ldots, (n-1)!.
$$

这使 $k$ 可以逐层除以阶乘。以元素 `[1,2,3,4]`、**0-based** 的 $k=14$ 为例：

- $3!=6$，$14/6=2$，首位选下标 $2$ 的 `3`，余数 $14\bmod 6=2$；
- 剩余 `[1,2,4]`，$2!=2$，$2/2=1$，选 `2`，余数 $0$；
- 剩余 `[1,4]`，$1!=1$，选下标 $0$ 的 `1`；
- 最后是 `4`。

所以第 $14$ 个排列为 `3214`。过程对应：

$$
14=2\times3!+1\times2!+0\times1!+0\times0!.
$$

实现时维护一个升序候选列表，每轮用 `k / fact` 选下标，再执行 `k %= fact`。朴素删除列表元素需要 $O(n^2)$；若 $n$ 很大且只要求排名/反排名，可用树状数组把“第几个未使用元素”的查找降到 $O(\log n)$，第七篇会说明其理论依据。

## 四、1-based 与 0-based 的陷阱

题目若说“第 $K$ 个”，常按人类习惯从 $1$ 开始。阶乘进制算法通常以 $0$ 为第一个编号，因此应先做：

$$
k=K-1.
$$

比如四元素的第 $15$ 个排列，转换后是 $k=14$，正是上例的 `3214`。少减这一，所有结果会整体错位一项；这是比算法本身更常见的错误。

## 五、什么时候用 next permutation，什么时候直接定位

- 需要从当前排列向后逐个处理少量结果：使用 `next_permutation`，每一步 $O(n)$。
- 需要第 $k$ 个结果而不需要前面的结果：使用阶乘分块，避免做 $k$ 次迭代。
- 需要全部结果：从升序排列反复调用 `next_permutation`，总输出复杂度仍为 $\Theta(n\cdot n!)$。
- 元素重复：字典序步骤仍可使用，但“块大小”不再只是简单阶乘，需要用多重集合排列数修正。

## 六、总结

- 字典序比较第一个不同位置；它让“下一个”和“第 $k$ 个”有明确含义。
- 下一个排列通过枢轴、后缀中刚大于枢轴的元素、反转后缀三步完成。
- 第 $k$ 个不同元素的排列可按 $(n-1)!,(n-2)!,\ldots$ 分块直接选择。
- 编号起点必须写清；题目 1-based 时先减一。

字典序解决了排列的“横向位置”。下一篇转向一个很有力量的“结构坐标”：一个排列中有多少对元素顺序颠倒，这便是逆序数。
