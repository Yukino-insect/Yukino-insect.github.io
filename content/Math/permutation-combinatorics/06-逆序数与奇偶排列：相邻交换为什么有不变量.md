把排列看成一个数组时，“有多少地方不按升序”不能只数相邻位置。例如 `[3,1,2]` 中，`3` 同时大于后面的 `1` 与 `2`；这种全局的颠倒对数称为**逆序数**。它不仅衡量无序程度，还决定了排列能否通过偶数次或奇数次相邻交换变回有序状态。

## 一、逆序数的定义

对于一个由不同数构成的排列 $p=(p_1,p_2,\ldots,p_n)$，若一对下标满足：

$$
i<j\quad\text{且}\quad p_i>p_j,
$$

则称 $(i,j)$ 是一个逆序对。全部逆序对的数量记为 $\operatorname{inv}(p)$。

例如 $p=(3,1,4,2)$：

- `3` 与后面的 `1`、`2` 构成两对；
- `4` 与后面的 `2` 构成一对；
- 其余没有。

故：

$$
\operatorname{inv}(3,1,4,2)=3.
$$

升序排列逆序数为 $0$；完全降序排列的每一对都逆序，因此最大值为：

$$
C_n^2=\frac{n(n-1)}2.
$$

## 二、相邻交换恰好改变一个逆序对

交换相邻元素 $x,y$。对于数组中其他元素 $z$，它与 $x,y$ 的相对左右关系整体不变：若 $z$ 在这两个位置左边或右边，它对这两个数贡献的逆序数总和不变。唯一改变的是 $(x,y)$ 这一对本身。

因此：

- 若原来 $x>y$，交换后消除一个逆序对，逆序数减 $1$；
- 若原来 $x<y$，交换后制造一个逆序对，逆序数加 $1$。

所以每做一次相邻交换，逆序数的奇偶性必然翻转。这给出**奇偶排列**：逆序数为偶数的排列叫偶排列，为奇数的叫奇排列。

## 三、为什么任意排序所需相邻交换次数的奇偶性固定

要将某排列通过相邻交换排成升序，终点逆序数是 $0$。由于每次交换使逆序数增减 $1$，无论你使用何种相邻交换策略，交换次数的奇偶性都与初始逆序数同奇偶。

例如 `(3,1,4,2)` 的逆序数为 $3$，任何把它排成升序的相邻交换序列都必须包含奇数次交换。冒泡排序会进行恰好 $3$ 次“交换相邻逆序对”，但其他路线可能绕远做 $5$、$7$ 次；它们都仍是奇数次。

这不是说每种交换次数都相同，而是说**奇偶性不变量**相同。若题目只允许每次交换相邻元素两次一组，便永远无法将奇排列变为升序排列。

## 四、逆序数怎样计算得更快

两层循环枚举所有 $(i,j)$ 需要 $O(n^2)$。归并排序合并两个有序段时可以在 $O(n\log n)$ 内统计逆序数：当右半段当前元素比左半段当前元素小，并被优先放入结果时，它会与左半段尚未合并的所有元素形成逆序对。

```cpp
long long mergeCount(vector<int>& a, vector<int>& temp, int left, int right) {
    if (right - left <= 1) return 0;
    int mid = left + (right - left) / 2;
    long long ans = mergeCount(a, temp, left, mid)
                  + mergeCount(a, temp, mid, right);

    int i = left, j = mid, k = left;
    while (i < mid && j < right) {
        if (a[i] <= a[j]) {
            temp[k++] = a[i++];
        } else {
            temp[k++] = a[j++];
            ans += mid - i;
        }
    }
    while (i < mid) temp[k++] = a[i++];
    while (j < right) temp[k++] = a[j++];
    for (int p = left; p < right; ++p) a[p] = temp[p];
    return ans;
}
```

当执行 `ans += mid - i` 时，左段 `a[i...mid)` 都大于当前右值：左、右两段各自已排序，且左段当前最小的未合并元素都更大。于是一次性计入这些交叉逆序对，而不是逐个比较。

若数值范围可离散化，也可用树状数组从左到右查询“此前有多少数比当前值大”，或从右到左查询“后面有多少数比当前小”，同样达到 $O(n\log n)$。

## 五、关于重复值的说明

标准排列理论中的奇偶性假设元素互异。含重复值的数组仍可按严格大于 `>` 定义逆序对，也可计算排序所需的最少交换等问题；但交换两个相等元素不会改变显示数组，却会改变给元素贴标签后的排列奇偶性。因此不应不加说明地把“多重集合序列”称为奇排列或偶排列。

## 六、总结

- 逆序数统计所有 $i<j,p_i>p_j$ 的颠倒对，不只看相邻位置。
- 一次相邻交换恰好让逆序数增减 $1$，故其奇偶性每次翻转。
- 排列的奇偶性是相邻交换下的不变量，解释了许多“能否到达”的问题。
- 归并排序或树状数组能把逆序数计算从 $O(n^2)$ 降到 $O(n\log n)$。
