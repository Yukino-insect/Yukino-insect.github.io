启动 Nacos 后，控制台可能打印类似下面的地址：

```bash
Console: http://192.168.182.1:8848/nacos/index.html
```

这个地址不一定是 `localhost`。Nacos 会根据本机网卡信息选择一个可访问 IP，并把它作为控制台访问提示打印出来。

## 一、为什么不是 localhost

`localhost` 只表示当前机器自己。Nacos 作为服务注册中心和配置中心，通常需要被其他机器访问，因此启动日志更倾向于打印一个本机局域网 IP。

如果机器有多块网卡，例如物理网卡、虚拟机网卡、Docker 网卡、VPN 网卡，Nacos 打印的地址可能不是期望中的那个。

## 二、是否影响访问

一般情况下，以下地址都可能访问同一个控制台：

```text
http://localhost:8848/nacos/
http://127.0.0.1:8848/nacos/
http://本机局域网IP:8848/nacos/
```

如果只是在本机访问，使用 `localhost` 即可。如果需要其他机器访问，就要使用对方能访问到的 IP。

## 三、配置建议

如果 Nacos 选错了 IP，可以检查网卡配置，或通过启动参数、配置项指定服务 IP。容器部署时尤其要注意宿主机 IP、容器 IP 和服务暴露端口之间的关系。

排查时可以先确认：

1. Nacos 是否监听在 `8848` 端口。
2. 防火墙是否放行。
3. 当前 IP 是否能被客户端访问。
4. 客户端配置的 `server-addr` 是否正确。

控制台地址只是访问提示，不代表只能用这个地址访问。
