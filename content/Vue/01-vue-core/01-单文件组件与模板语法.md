Vue 单文件组件通常以 `.vue` 结尾，它把逻辑、模板和样式放在同一个文件中。这样做不是为了把所有东西塞在一起，而是为了把一个组件相关的内容聚合起来。

## 一、单文件组件结构

典型结构：

```vue
<script setup lang="ts">
const title = '文章列表'
</script>

<template>
  <section class="page">
    <h2>{{ title }}</h2>
  </section>
</template>

<style scoped>
.page {
  padding: 16px;
}
</style>
```

三部分职责：

- `<script setup>`：声明状态、函数、导入模块。
- `<template>`：描述页面结构。
- `<style scoped>`：编写组件样式。

## 二、插值

模板中使用双大括号显示文本：

```vue
<template>
  <p>{{ username }}</p>
</template>
```

插值会把表达式结果转成文本，不会当成 HTML 解析。这样可以避免一部分 XSS 风险。

如果确实要渲染 HTML，需要 `v-html`，但要非常谨慎：

```vue
<div v-html="html"></div>
```

外部输入不要直接 `v-html`。安全问题不会因为你没看见就不存在。

## 三、属性绑定

使用 `v-bind`，简写为 `:`。

```vue
<img :src="avatarUrl" :alt="username">
```

绑定 class：

```vue
<button :class="{ active: selected, disabled: loading }">
  提交
</button>
```

绑定多个 class：

```vue
<div :class="['card', sizeClass, { highlighted }]"></div>
```

## 四、事件绑定

使用 `v-on`，简写为 `@`。

```vue
<button @click="submit">提交</button>
```

带参数：

```vue
<button @click="removeItem(item.id)">删除</button>
```

事件对象：

```vue
<input @input="handleInput">
```

```ts
function handleInput(event: Event) {
  const target = event.target as HTMLInputElement
  keyword.value = target.value
}
```

## 五、条件渲染

`v-if` 会决定元素是否创建。

```vue
<div v-if="loading">加载中</div>
<div v-else-if="error">加载失败</div>
<div v-else>内容</div>
```

`v-show` 会通过 CSS 控制显示隐藏，元素仍然存在。

```vue
<div v-show="visible">弹窗内容</div>
```

选择原则：

- 切换频率低：`v-if`。
- 切换频率高：`v-show`。

## 六、列表渲染

使用 `v-for`：

```vue
<article v-for="post in posts" :key="post.id">
  <h3>{{ post.title }}</h3>
  <p>{{ post.summary }}</p>
</article>
```

`key` 必须稳定，优先使用业务 id。不要随手用数组下标。

数组下标作为 key 在增删排序时容易导致组件复用错误，表现为输入框内容错位、状态串到另一项上。

## 七、表单绑定

`v-model` 用于双向绑定。

```vue
<input v-model="form.username">
<textarea v-model="form.content"></textarea>
```

修饰符：

```vue
<input v-model.trim="form.title">
<input v-model.number="form.age">
```

`v-model` 方便，但不要因此忽视校验。用户输入永远不该被默认信任。

## 八、模板表达式不要太复杂

不推荐：

```vue
<p>{{ user.profile?.nickname ?? user.username ?? '匿名用户' }}</p>
```

推荐用 `computed`：

```ts
const displayName = computed(() => {
  return user.value.profile?.nickname ?? user.value.username ?? '匿名用户'
})
```

```vue
<p>{{ displayName }}</p>
```

模板应该表达结构，不应该承担太多业务计算。

## 九、scoped 样式

`scoped` 会让样式只作用于当前组件。

```vue
<style scoped>
.card {
  border: 1px solid #ddd;
}
</style>
```

它不是绝对隔离，而是通过属性选择器实现作用域。公共变量、重置样式和主题样式仍然适合放到全局样式文件。

## 十、实战落点：模板应该表达页面状态

写模板时不要只想着“把内容显示出来”。一个成熟组件至少要考虑：输入数据是否完整、按钮状态是否可操作、事件是否能把用户意图传出去、样式是否只依赖明确状态。模板不是摆设，它是业务状态的可视化结果。

## 十一、练习讲解：实现文章卡片组件

实现一个文章卡片组件：

- 接收标题、摘要、作者、点赞数。
- 点赞按钮点击后触发事件。
- 没有摘要时显示默认文案。
- 根据是否已点赞切换按钮 class。

这个练习覆盖 `props`、模板插值、属性绑定、事件绑定、条件展示和 class 绑定。先把页面写顺，再谈组件抽象，顺序不能反。

### 1. 运行步骤

```bash
npm create vite@latest vue-card-demo -- --template vue-ts
cd vue-card-demo
npm install
npm run dev
```

### 2. 创建 `src/components/PostCard.vue`

```vue
<script setup lang="ts">
type Props = {
  title: string
  summary?: string
  author: string
  likes: number
  liked: boolean
}

const props = withDefaults(defineProps<Props>(), {
  summary: ''
})

const emit = defineEmits<{
  like: []
}>()
</script>

<template>
  <article class="post-card">
    <div class="content">
      <h2>{{ title }}</h2>
      <p>{{ summary || '这篇文章还没有摘要。作者很可能以为标题已经足够说明一切。' }}</p>
      <span>作者：{{ author }}</span>
    </div>

    <button
      class="like-button"
      :class="{ active: liked }"
      :aria-pressed="liked"
      @click="emit('like')"
    >
      {{ liked ? '已点赞' : '点赞' }} · {{ likes }}
    </button>
  </article>
</template>

<style scoped>
```

### 3. 替换 `src/App.vue`

```vue
<script setup lang="ts">
import { ref } from 'vue'
import PostCard from './components/PostCard.vue'

const post = ref({
  title: '单文件组件不是把代码随便塞进一个文件',
  summary: '',
  author: 'Yuki',
  likes: 7,
  liked: false
})

function handleLike() {
  post.value.liked = !post.value.liked
  post.value.likes += post.value.liked ? 1 : -1
}
</script>

<template>
  <main class="page">
    <PostCard
      :title="post.title"
      :summary="post.summary"
      :author="post.author"
      :likes="post.likes"
      :liked="post.liked"
      @like="handleLike"
    />
  </main>
</template>

<style scoped>
.page {
  max-width: 760px;
  margin: 0 auto;
  padding: 32px 20px;
  background: #f8fafc;
  min-height: 100vh;
}
</style>
```

### 4. 关键点解释

- `PostCard` 不直接修改点赞数据，只通过 `emit('like')` 通知父组件。
- `summary || 默认文案` 处理了摘要为空的展示。
- `:class="{ active: liked }"` 让样式跟着状态变化。
- `aria-pressed` 让按钮语义更完整，对可访问性更友好。
