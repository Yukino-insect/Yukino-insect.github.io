这套 Vue 专题面向已经掌握 HTML、CSS、JavaScript 基础，想把 Vue 真正用于业务项目的学习者。它不会只停留在 `v-if`、`v-for`、`ref` 这些 API 名词上，因为那样学完之后通常只会得到一种错觉：好像会 Vue 了，但一遇到登录、接口、分页、权限、错误态、构建部署，代码立刻开始东倒西歪。很遗憾，项目不会因为你背过 API 就变得体贴。

课程按真实前端应用的成长路径组织：先理解 Vue 页面和响应式，再拆组件、管状态、处理接口和表单，最后进入路由、跨端、测试、性能、部署和大型项目结构。每篇文章最后都给出可运行练习，综合练习则从零搭建一个“文章管理后台”小项目，把组件、Pinia、路由、表单、错误态和本地模拟接口串起来。

## 推荐学习顺序

1. 先读 `01-vue-core/`，把 Vue 页面、模板和响应式讲清楚。
2. 再读 `02-state-data/`，把组件拆分、接口请求、Pinia 和业务状态串起来。
3. 接着读 `03-engineering/`，补齐路由、uni-app、性能、测试、构建和目录边界。
4. 最后完成 `04-final-project/`，用一个小项目把前面的知识真正跑通。

## 学习方法

每一篇文章都建议带着三个问题读：

1. 这段状态应该放在组件内、父组件、Pinia，还是 URL 里？
2. 这个页面除了成功状态，还需要处理哪些失败、空态和权限状态？
3. 这段代码如果三个月后需求变化，我能不能清楚地知道该改哪里？

能持续回答这三个问题，才算从“会写 Vue 语法”走向“能写 Vue 项目”。只是让页面亮起来并不难，让它在需求变化、接口波动和多人协作中还保持清醒，才是前端工程能力。
